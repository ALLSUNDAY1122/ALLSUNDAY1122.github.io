### 1. 2025-10-Q35（新規）

**問題文案**：職場健診でAは高血糖かつ尿糖陽性、Bは血糖値が正常範囲だが尿糖陽性だった。結果の違いを説明する考え方として最も適切なのはどれか。

- index 0：Aの尿糖は膀胱で新たに糖が合成されたためである
- index 1：尿糖陽性なら血糖に関係なく糖尿病と確定する
- index 2：Bは血糖正常なので尿糖が生じる機序は存在しない
- index 3：高血糖時は尿細管の糖回収能力が無制限に増えるため尿糖は生じない
- index 4：Aでは濾過負荷が糖再吸収能力を上回る可能性があり、Bでは尿細管の糖再吸収低下などを検討する

**正答案**：index 4：Aでは濾過負荷が糖再吸収能力を上回る可能性があり、Bでは尿細管の糖再吸収低下などを検討する

**解説案**：尿糖陽性だけでは原因を確定できない。Aは濾過されるブドウ糖の負荷が再吸収能力を上回り得る。Bでは腎性糖尿や薬剤の作用等も考慮する。肢0は糖合成場所が誤り、1は診断の飛躍、2は正常血糖での尿糖を否定し、3は輸送能力の上限を無視している。

### 2. 2025-10-Q38（新規）

**問題文案**：胃酸分泌が低下したAと、小腸粘膜のエンテロペプチダーゼ活性が低下したBを想定する。蛋白質分解酵素の前駆体活性化について適切なのはどれか。

- index 0：Aでは胃内のペプシノーゲン活性化が、Bでは小腸のトリプシノーゲン活性化が、それぞれ影響を受け得る
- index 1：Aではトリプシノーゲンが必ず胃壁でのみ活性化される
- index 2：Bの酵素活性低下はトリプシノーゲンの活性化に影響しない
- index 3：ペプシノーゲンもトリプシノーゲンも胆汁に活性型で分泌される
- index 4：両酵素は胃酸と小腸粘膜の状態によらず必ず同一部位で活性化される

**正答案**：index 0：Aでは胃内のペプシノーゲン活性化が、Bでは小腸のトリプシノーゲン活性化が、それぞれ影響を受け得る

**解説案**：胃内の酸性環境はペプシノーゲンの活性化に関わり、小腸刷子縁のエンテロペプチダーゼは膵由来トリプシノーゲンの活性化に関わる。肢1・4は部位の混同、2はエンテロペプチダーゼの機能否定、3は分泌臓器と活性型を誤認する。

### 3. practice-B-Q36（既存案を確定）

**問題文案**：安静呼吸では支障のない人が、短時間に勢いよく息を吐く際だけ腹部の筋収縮を意識した。安静呼息と努力性呼息の機序の違いについて適切なのはどれか。

- index 0：安静呼息は常に腹筋の最大収縮を要する
- index 1：努力性呼息中は肺胞圧が大気より低くなる
- index 2：安静呼息は主に弾性復元、努力性では腹筋等の活動が加わる
- index 3：呼息は横隔膜の収縮のみに依存する
- index 4：努力性呼息で腹筋は胸郭内圧に作用しない

**正答案**：index 2：安静呼息は主に弾性復元、努力性では腹筋等の活動が加わる

**解説案**：安静呼息は通常、吸息筋の活動低下と呼吸器の弾性復元による。努力性呼息では腹筋等が加わる。肢0は腹筋最大収縮を必須とする誤り、1は呼出時の圧差が逆、3は横隔膜だけに帰属、4は腹筋作用を否定する。

### 4. practice-B-Q37（既存案を確定）

**問題文案**：ある測定時間30秒間に安定した呼吸が9回あり、1回に出入りした空気量を0.45Lと評価した。同じ呼吸条件が1分続くと仮定した場合の分時換気量はどれか。

- index 0：4.05L/分
- index 1：8.1L/分
- index 2：9.0L/分
- index 3：18L/分
- index 4：0.45L/分

**正答案**：index 1：8.1L/分

**解説案**：30秒間9回は1分当たり18回。分時換気量は0.45L×18=8.1L/分で、死腔換気量を除いた肺胞換気量とは異なる。肢0は30秒間の積算量、肢2・3は計算上の誤り、肢4は一回換気量のまま。

### 5. practice-B-Q38（既存案を確定）

**問題文案**：呼吸機能の簡易記録で一回換気量0.6L、予備吸気量2.2L、予備呼気量1.1L、残気量1.4Lと得た。肺活量として算入すべき値はどれか。

- index 0：2.8L
- index 1：3.3L
- index 2：3.9L
- index 3：5.3L
- index 4：1.4L

**正答案**：index 2：3.9L

**解説案**：肺活量は一回換気量・予備吸気量・予備呼気量の合計で、0.6+2.2+1.1=3.9L。残気量は肺活量に含まれない。肢0は予備呼気量を欠き、肢1は数値の誤り、肢3は残気量を加えた全肺気量、肢4は残気量のみ。

### 6. practice-B-Q42（新規）

**問題文案**：暑い環境で長時間働き水分補給が不足した人で、血漿浸透圧上昇に伴いADH作用が強まった。腎集合管で起こり得る変化として適切なのはどれか。

- index 0：水透過性が低下し尿量は必ず増加する
- index 1：集合管の水透過性は調節されず尿の濃さは腎血流だけで決まる
- index 2：ADHは糸球体でブドウ糖を合成する酵素である
- index 3：集合管の水再吸収が促され、水の保持・尿量減少や尿濃縮につながり得る
- index 4：集合管では水再吸収が起きないためADHの影響はない

**正答案**：index 3：集合管の水再吸収が促され、水の保持・尿量減少や尿濃縮につながり得る

**解説案**：ADHは集合管などで水透過性を高め、水再吸収を促し得る。肢0は作用方向が逆、1は集合管での調節否定、2はホルモンと酵素の混同、4は集合管の水再吸収を否定している。尿量の変化には別の条件も影響するため一律の断定は避ける。

### 7. practice-B-Q43（既存案を確定）

**問題文案**：糸球体から出た血液が周囲の毛細血管へ向かうのと同時に、濾過液はボーマン嚢から尿細管へ入る。血液と濾液の最初の分岐を正しく説明する組合せはどれか。

- index 0：血液は輸出細動脈、濾液は尿細管へ
- index 1：血液はボーマン嚢、濾液は輸出細動脈へ
- index 2：血液は集合管、濾液は輸入細動脈へ
- index 3：血液・濾液とも尿細管周囲毛細血管へ
- index 4：血液・濾液とも輸出細動脈へ

**正答案**：index 0：血液は輸出細動脈、濾液は尿細管へ

**解説案**：糸球体から血液は輸出細動脈を経て血管系へ、濾液はボーマン嚢腔から尿細管へ進む。肢1は両経路の逆転、2は集合管と細動脈を混同、3・4は両者を同一経路としている。
