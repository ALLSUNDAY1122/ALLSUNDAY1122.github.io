### practice-B-Q38

### practice-B-Q42
- 正答index：`3`
- 問題文：腎臓で脱水への適応が進み、抗利尿ホルモン（ADH）の作用が強まった。ネフロン各区間の水移動と濾液の流れる順序を合わせて考えると、最も適切な説明はどれか。
- 選択肢：
  - index 0：近位尿細管を出た濾液は遠位尿細管を経ず直接集合管へ入り、ADHは近位尿細管だけの水再吸収を増やす
  - index 1：濾液は集合管→遠位尿細管→ヘンレ係蹄の順に流れ、集合管での水再吸収はADHと無関係で一定となる
  - index 2：ヘンレ係蹄の上行脚は水に高い透過性を持つため、ADH上昇による尿濃縮は上行脚だけで完結する
  - index 3：近位尿細管→ヘンレ係蹄→遠位尿細管→集合管の順に進み、ADH作用により集合管などでの水再吸収が増え得る
  - index 4：集合管へ流入した濾液は通常そこで再吸収されず、水はすべて最終尿となる
- 解説detail：濾液は近位尿細管、ヘンレ係蹄、遠位尿細管を経て集合管へ進む。ADHの作用は集合管などの水透過性と水再吸収を高めて尿の濃縮に寄与するため肢3が妥当。肢0は区間と作用部位を誤り、2は上行脚での水移動と尿濃縮の機序を混同、3は流路を逆転しADH作用を否定、4は集合管の可変的水再吸収を否定。Q43の血液と濾液の区画の違いとは別命題。

### practice-B-Q44
- 正答index：`0`
- 問題文：糸球体で濾過され近位尿細管に達したブドウ糖の負荷が増え、ブドウ糖輸送担体の再吸収能力を上回った。別の物質については尿細管周囲毛細血管側から尿細管腔への分泌が続いている。最も適切な説明はどれか。
- 選択肢：
  - index 0：ブドウ糖の再吸収能力を超えた分は尿中に現れ得るが、血液側から尿細管腔への物質移動は尿細管分泌であり、再吸収とは向きが異なる
  - index 1：ブドウ糖再吸収担体が飽和すると糸球体濾過が直ちに停止するので、尿中ブドウ糖は増えない
  - index 2：近位尿細管でのブドウ糖再吸収は輸送担体の容量に左右されず、濾過量が増えてもすべて必ず再吸収される
  - index 3：血液側から尿細管腔へ物質を輸送することは再吸収に分類されるため、分泌は濾過の別名である
  - index 4：ブドウ糖の再吸収能力を超えた場合、尿細管分泌により余剰ブドウ糖がすべて血液へ戻される
- 解説detail：近位尿細管でのブドウ糖再吸収はNa共輸送などの担体の輸送容量に制約される。濾過負荷が再吸収能力を超えればブドウ糖が尿中に現れ得る。尿細管分泌は毛細血管側から尿細管腔への移送で、再吸収は逆方向のため肢0が正しい。肢1は担体飽和と糸球体濾過を混同、2は輸送最大値を無視、3は分泌と再吸収の方向を逆に記載、4は余剰分を無条件に血液へ戻すと断定。Q41は水の定量収支、Q42はADHと濾液経路で別命題。
