## MVP範囲

- 60問：必修24／一般24／状況設定12
- 今日の12問

- 科目・領域別
- 単一選択：選択肢タップで即時採点

## コンテンツの扱い

MVP60問は独自作成。過去問本文の転載を前提にしない。各問題に `rightsStatus: original-mvp` と `sourceStatus: official-review-pending` を付与している。

厚生労働省の最新出題基準、公開問題の利用条件、最新制度・統計・ガイドラインの公式監査が完了するまで、MVP問題を製品版データへ自動昇格させない。

## 製品版目標

- 240問相当 × 3セット = 720問を基本目標
- 必修／一般／状況設定を独立集計
- 本番形式では即時採点OFF
- 年度別の試験構成・合格判定条件は `examConfig` でデータ駆動
- 画像・図表問題は権利確認済みアセットのみ本番投入
- StoreKit 2で月額＋買い切り候補を実装し、表示価格は `displayPrice` を使用

## CI

`.github/workflows/kangoshi-sprint-ci.yml` が以下を監査する。

- `questions.js` / `app.js` の構文
- 60問構成（24／24／12）
- 問題ID重複
- 問題文重複
- 正答インデックス
- 複数選択数
- 解説欠落
- 権利・公式監査フラグ欠落
- 状況設定のscenario欠落
