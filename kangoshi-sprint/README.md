## 公式仕様確認

2026-08-08に厚生労働省の第115回看護師国家試験資料、実施情報、合格発表、令和5年版出題基準、ウェブサイト利用規約を確認した。

- 第115回は午前120問＋午後120問、各2時間40分
- 回答形式は単一選択、2つ選択、数値計算を含む
- 第115回合格基準は必修40/50以上、一般＋状況設定166/249以上
- 採点除外等があるため、製品版の基準点・配点・除外問題は年度別 `examConfig` で管理する
- 科目マスタは厚生労働省の11科目を基準にする

詳細は `OFFICIAL_AUDIT_2026-08-08.md` を参照。

## 製品版目標

- 240問 × 3セット = 720問を基本目標
- 必修／一般／状況設定を独立集計
- 本番形式では即時採点OFF
- 年度別の試験構成・合格判定条件・採点除外を `examConfig` でデータ駆動
- 画像・図表問題は権利確認済みアセットのみ本番投入
- StoreKit 2で月額＋買い切り候補を実装し、表示価格は `displayPrice` を使用
