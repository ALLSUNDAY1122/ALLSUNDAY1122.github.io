# App Review / TestFlight Notes

更新: 2026-08-15

## Review Notes
看護師国家試験の学習用問題演習アプリです。ログインは不要です。

起動後、無料状態で次を確認できます。
1. ホーム → 「今日のスプリント」
2. ホーム → 「無料お試し」→ 必修 / 一般 / 状況設定
3. 模試タブ → プレミアム案内
4. 設定タブ → 「購入を復元」

プレミアムはApple StoreKit 2による自動更新サブスクリプションです。商品IDは `jp.allsunday1122.kangoshi.monthly`。価格表示はStoreKitの `Product.displayPrice` を使用し、アプリ内へ価格文字列を固定していません。

購入後に解放される主な機能:
- 苦手復習
- 分野別学習
- 第115・114・113回の本番形式
- 詳細な学習記録

購入復元はプレミアム画面と設定画面の双方にあります。

問題は720問（各試験回240問）をアプリ内に同梱しています。外部アカウント、広告、行動解析、独自サーバー通信はありません。学習記録は端末内保存です。

本アプリは厚生労働省その他の公的機関が提供・承認する公式アプリではありません。出典・利用条件を確認した公開資料と、独自に作成した学習用図版を使用しています。

## Internal TestFlight 実機確認項目
- 起動してホームが表示される
- 今日のスプリント開始 / 回答 / 解説 / 次へ / 閉じる
- 必修・一般・状況設定の無料お試し
- 図版問題が欠けずに表示される
- 第115・114・113回が各240問構成である
- 特殊採点問題が通常問題と同じ扱いになっていない
- 購入画面の価格がStoreKit由来で表示される
- 購入 / 解約済み状態 / 購入復元
- 設定4・8・16問
- 学習記録保存とリセット
- 小型画面と現行大型iPhoneでレイアウト崩れがない

## 本審査境界
Internal TestFlight実機確認後も、`Add for Review` / `Submit for Review` はユーザー承認なしに実行しない。
