# ネットワークスペシャリスト｜問題難易度監査

更新: 2026-08-21

## 結論
現行75問を再監査し、知識なしでも語感・選択肢の異分野混在・単純用語対応だけで正答しやすい43問を試験水準へ改稿した。

## 採用基準
- ネットワーク知識がなくても日本語だけで消去できる設問は不採用。
- 正解だけが明らかに別カテゴリ・具体的で、誤答が無関係語という選択肢構成を避ける。
- 単純な『用語→定義』は、構成・状態・運用・障害・パケット挙動の文脈へ置換する。
- 計算問題は単位変換、サブネット範囲、確率、トラフィック量など最低1段階の処理を要求する。
- プロトコル問題は、OSI層・方向・メッセージ種別・ポート/Protocol番号・状態遷移などを混同しやすい選択肢で識別させる。
- セキュリティ問題は、攻撃名の暗記だけでなく攻撃経路・成立条件・適切な対策を判断させる。

## 実施
- 75問中43問を `questions-difficulty-overrides.js` で改稿。
- 改稿問題には `difficultyLevel = NW_A2_EXAM` を付与。
- Web版は問題読込み後に同じoverrideを適用。
- ネイティブ版は `build_native_questions.py` が同じoverrideを取り込み、43問以上の試験水準監査済み問題が存在しなければビルドを失敗させる。
- Service Worker cacheをv2へ更新し、難易度overrideを配布対象へ追加。

## 維持した問題
残り32問は、MSS、BER、CIDR集約、VLSM、アーラン、Ethernetフレーム長、スパニングツリー最短経路、IPsec ESP暗号範囲など、既に知識適用または計算を要求しており、単純な語感回答になっていないため維持。

## Release Gate
`build_native_questions.py` で以下を必須化。
- 75 occurrences
- 68 unique concepts
- 各年度25問
- 4択重複なし
- `NW_A2_EXAM` 監査済み問題40問以上

現行値は43問。今後、易問へ後退して40問未満になった場合はnative question payload生成をFAILさせる。
