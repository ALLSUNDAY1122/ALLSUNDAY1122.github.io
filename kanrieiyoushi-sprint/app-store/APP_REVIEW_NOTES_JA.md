# App Review Notes｜管理栄養士 学びスプリント

本アプリは管理栄養士国家試験向けの学習アプリです。ログインはありません。

## App内課金
- 商品: `jp.allsunday1122.kanrieiyoushi.premium`
- 種別: Non-Consumable（買い切り）
- 無料範囲: 第1回の10分類×各6問＝60問
- 購入後: 全600問、200問模試×3、全苦手復習、詳細記録を解放
- 購入ボタンはStoreKitの商品情報が取得でき、`displayPrice`が表示できた場合のみ有効化します。
- 復元: 設定画面またはプレミアム画面の「購入を復元」から明示的に実行できます。
- pending / userCancelled / revocation / transaction updates に対応しています。

## 確認手順
1. 起動後「今日のスプリント」で無料問題を開始できます。
2. 第2回・第3回、模試、詳細記録などのロック対象を選ぶとプレミアム画面が開きます。
3. 「購入を復元」は設定画面にも常時表示されます。
4. 購入済み権利は起動時にStoreKit 2 `Transaction.currentEntitlements` から再確認します。

## データ・プライバシー
アカウント、広告SDK、解析SDKはありません。学習履歴は端末内に保存します。決済情報はAppleが処理し、本アプリはカード情報を取得しません。

本アプリは厚生労働省の公式アプリではありません。
