# 仕訳スワイプ

日商簿記3級・2級の仕訳判断を、左右スワイプで反復するゲーム型学習アプリのMVPです。

- 左スワイプ：借方
- 右スワイプ：貸方
- スコアアタック
- 60秒タイムアタック
- 問題別履歴に基づく苦手出題
- 日付固定のデイリー10問
- 級別出題（3級・2級・両方）
- 論点別正答率
- オフラインキャッシュ
- 端末内保存のみ

## 公開URL

GitHub Pagesのサブディレクトリとして公開します。

`https://allsunday1122.github.io/shiwake-swipe/`

## ローカル確認

JSONをfetchするため、ファイルを直接開かず簡易HTTPサーバーを使用します。

```bash
python -m http.server 8000
```

## データ構造

`data/questions.json` の各問題は次の項目を持ちます。

- `id`
- `grade`
- `category`
- `transaction`
- `account`
- `correctSide` (`debit` / `credit`)
- `explanation`
- `journal`

問題追加時は、同一取引について借方科目と貸方科目の両方をカード化します。

## 品質上の注意

問題は独自作成の試作データです。公式問題ではありません。公開前に簿記有資格者による全問監修、現行出題区分との照合、表記統一が必要です。
