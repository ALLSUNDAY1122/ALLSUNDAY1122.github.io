# 仕訳スワイプ App Store公開チェックリスト

## A. 学習内容

- [ ] 44取引・88カードを全件監修する
- [ ] 日商簿記の現行出題区分と照合する
- [ ] 3級・2級の級区分を再確認する
- [ ] 勘定科目名、金額表記、句読点を統一する
- [ ] 借方・貸方、理由、完成仕訳の4項目を照合する
- [ ] 工業簿記と連結会計の説明を重点確認する
- [ ] 誤り報告を受けた問題を追跡できる管理番号を維持する

## B. Flutterプロジェクト

- [ ] MacまたはMacinCloudへリポジトリを取得する
- [ ] Flutter stableを導入する
- [ ] `shiwake-swipe/flutter_app` で `flutter create --platforms=ios,android .` を実行する
- [ ] 生成差分で既存の `lib/`、`assets/`、`pubspec.yaml` が壊れていないことを確認する
- [ ] `flutter pub get` を実行する
- [ ] `dart format lib test` を実行する
- [ ] `flutter analyze --no-fatal-infos` を実行する
- [ ] `flutter test` を実行する
- [ ] iPhoneシミュレータで全4モードを確認する
- [ ] iPhone 16実機で左右スワイプと振動を確認する
- [ ] 画面回転を縦向きに制限する
- [ ] VoiceOverで主要ボタンと問題文を確認する
- [ ] 文字サイズを上げても重要情報が欠けないことを確認する

## C. iOS設定

- [ ] Bundle IDを確定する
- [ ] Apple DeveloperのTeamを設定する
- [ ] Signingを自動管理に設定する
- [ ] Display Nameを設定する
- [ ] Versionを`1.0.0`、Buildを`1`に設定する
- [ ] 対応する最低iOSバージョンを確定する
- [ ] アプリが不要な権限を要求していないことを確認する
- [ ] App Transport Securityの例外を追加していないことを確認する
- [ ] Privacy Manifestを依存SDKを含めて確認する
- [ ] Releaseビルドでクラッシュしないことを確認する

## D. アイコン・画面素材

- [ ] 1024×1024のApp StoreアイコンをPNGで作成する
- [ ] 透明部分、角丸の焼き込み、文字の細かすぎる表示がないことを確認する
- [ ] XcodeのAppIconへ必要サイズを登録する
- [ ] 指定端末サイズのスクリーンショットを作成する
- [ ] スクリーンショット内の機能が実装済みであることを確認する
- [ ] 画像内の日本語表記を校正する
- [ ] ダーク画面でも文字が読めることを確認する

## E. App Store Connect

- [ ] 新規アプリレコードを作成する
- [ ] アプリ名、サブタイトル、カテゴリ、SKU、Bundle IDを入力する
- [ ] 説明文、キーワード、プロモーションテキストを入力する
- [ ] プライバシーポリシーURLを登録する
- [ ] サポートURLを登録する
- [ ] サポートページに実際の問い合わせ手段があることを確認する
- [ ] App Privacyの回答を実装と照合する
- [ ] 年齢制限指定の質問票へ回答する
- [ ] コンテンツ権利に関する質問へ回答する
- [ ] 輸出コンプライアンスの暗号化質問へ回答する
- [ ] 価格と配信地域を設定する
- [ ] 著作権表記を確定する

## F. TestFlight

- [ ] XcodeからArchiveを作成する
- [ ] Validate Appを実行する
- [ ] App Store Connectへアップロードする
- [ ] ビルド処理完了後、内部テスターへ配信する
- [ ] 初回起動、全モード、再起動後の成績保存を確認する
- [ ] オフライン状態で全機能を確認する
- [ ] アプリ削除・再インストール時の記録初期化を確認する
- [ ] 長時間のタイムアタック連続実行でタイマー異常がないことを確認する
- [ ] バックグラウンド復帰時のタイマー挙動を確認する
- [ ] 不具合を修正し、Build番号を上げて再提出する

## G. 審査提出

- [ ] 審査用ビルドを選択する
- [ ] App Review向け操作説明を入力する
- [ ] ログイン情報不要であることを記載する
- [ ] 連絡先情報を入力する
- [ ] スクリーンショットとメタデータを最終確認する
- [ ] 「Add for Review」後、提出内容を確認する
- [ ] 「Submit for Review」を実行する
- [ ] 審査メッセージを確認できる状態にする

## H. 公開後

- [ ] App Storeの製品ページを確認する
- [ ] インストールと初回起動を確認する
- [ ] サポート窓口を監視する
- [ ] 問題誤りを優先度高で修正する
- [ ] クラッシュとレビュー内容を確認する
- [ ] 次版の問題追加・課金導入を別管理する
