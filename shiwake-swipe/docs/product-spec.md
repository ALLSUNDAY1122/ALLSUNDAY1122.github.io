# 仕訳スワイプ MVP仕様書

## 1. プロダクト目的

簿記学習者が、勘定科目を借方・貸方のどちらに置くかを短時間で反復し、仕訳判断の速度と正確性を高める。

## 2. 想定ユーザー

- 日商簿記3級を初めて学ぶ人
- 日商簿記2級の商業簿記・工業簿記を復習する人
- 1〜3分の隙間時間で学びたい人

## 3. コア操作

- 取引文と対象勘定科目を表示する。
- 借方なら左、貸方なら右へカードをスワイプする。
- 正誤、理由、完成仕訳を即時表示する。
- 同じ取引の借方科目・貸方科目を別カードとして出題する。

## 4. ゲームモード

### スコアアタック
- ライフ3
- 誤答でライフを1消費
- 正解、回答速度、コンボにより加点
- ライフ0で終了

### タイムアタック
- 60秒
- 時間内に連続出題
- 解説を短時間表示後に自動進行

### 苦手出題
- 問題別の回答数・正解数を端末内保存
- 誤答率の高い既出問題を優先
- 未回答問題も一部混ぜる
- 10問で終了

### デイリー10問
- 日付、選択級をもとに決定的にシャッフル
- 同じ日・同じ級では同一セット

## 5. スコア式（試作）

`100 + 速度点 + コンボ点`

- 速度点：最大50点、0.1秒ごとに1点減少
- コンボ点：1連続につき5点、最大100点

## 6. 学習データ

端末内に以下を保存する。

- 総回答数
- 総正解数
- 最高コンボ
- モード・級別自己ベスト
- 問題別回答数・正解数・最終回答日時
- 選択級・効果音設定

外部送信は行わない。

## 7. 初回リリース範囲

- 3級：基本取引、商品売買、債権債務、現金預金、収益費用、固定資産、前払・前受、決算整理
- 2級：有価証券、社債、株式会社会計、電子記録債権債務、引当金、無形固定資産、リース、連結基礎、工業簿記

## 8. 収益化案

広告より買い切り型を優先する。

- 無料：3級の基本問題、デイリー、簡易成績
- 買い切り：3級全問題、2級全問題、詳細分析、広告非表示
- 将来：問題パック追加

## 9. App Store化の方針

- FlutterでiOSアプリ化
- iPhone縦画面を主対象
- ネット接続不要
- 個人情報の登録不要
- 初回版はオンラインランキングなし
- 利用データは端末内保存

## 10. 公開前チェック

- 全問題を複数名で監修
- 日商簿記の現行出題区分と照合
- 勘定科目表記を統一
- VoiceOverで主要操作を確認
- 320px幅から大型iPhoneまで確認
- オフライン起動を確認
- プライバシーポリシーとサポートURLを用意
