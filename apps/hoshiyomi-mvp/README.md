# 星詠み Next.js MVP v0.3 — コンテンツ品質改修版

## 実装済み
- 主要日本語占いサイト10件の構成を参考にしたオリジナルのストーリー構成
- 12太陽星座すべてに固有の導入・四元素・三区分・支配星・長所と影・恋愛/仕事のテーマ
- 3ジャンル × 3つの悩み × 3段階の状況。無料は背景解説＋5項目の読み解きで完結
- 有料は7日間の行動計画、言葉の例、観察指標、行き詰まった場合の代替案。無料サンプル表示
- 決済ボタンは品質検証段階では無効（Stripe APIコード自体は存在する）

## 品質規則
- 太陽星座は月日だけから判定。出生時刻を必要とする月星座、アセンダント、トランジット、アスペクト等を計算したとは主張しない
- 天文学的検証をしていない「今日は金星が○○座に入った」等の記述を自動生成しない
- 占星術の文化的な解釈と、実生活の行動アドバイスの出所を混同しない
- 他サイトの占い文は転載しない。固有のキャッチコピーや文章の模倣も避ける
- 支払い意思決定を恐怖、依存、相手の気持ち断定で誘導しない

## 接続・起動
npm install && npm run build && npm run dev
専用環境変数は .env.example 参照。外部決済・DB接続は未検証。mainマージ・本番決済は禁止。
