# 星詠み MVP v0.6｜多層占いと関係鑑定

## 方針
有料版の価値を「行動計画／会話例／代替案」から、占術・入力情報を追加して深く楽しめる鑑定へ変更した。旧 premium-kit.ts は廃止。

## 無料
太陽星座（誕生月日）の物語、四元素、三区分、支配星、現在の関心に沿った読み物。ユーザー自身の情報は保存しない。

## 深い鑑定（品質検証中・無料開放）
1. 出生年→日本の十二支（暦年基準、立春/旧正月基準ではない）
2. 生年月日→単純加算の数秘1〜9（独自解釈、厳密な伝統術の再現ではない）
3. 血液型→任意の娯楽的な象徴。性格との科学的相関を主張しない
4. 大切な相手の誕生月日→2人の太陽星座の物語。相手の出生年、血液型は任意
5. 親の誕生月日と出生年→家族の星座物語。親の気持ちを断定しない

鑑定はクライアント内で生成、入力の保存や送信は行わない。利用者が他者の個人情報を入力するときの配慮を表示する。

予定価格は本人の多層鑑定480円・二人の関係鑑定980円だが、**Stripe未接続、本番販売なし**。評価期間中は全内容を無料閲覧できる。

## デプロイ
Vercelのプレビューデプロイで動作確認。現在 GitHubブランチ `feature/hoshiyomi-mvp-20261105` のみ変更。mainは未マージ。
