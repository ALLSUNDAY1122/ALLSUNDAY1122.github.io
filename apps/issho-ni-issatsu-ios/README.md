# いっしょに一冊 — Stage 7

外出中の短い時間を、受け身の動画視聴ではなく、親子が同じ絵を見て言葉を交わす時間へ変えるSwiftUI絵本アプリです。

## 実装範囲

- 収録絵本10冊（JSONデータ）
- 親が読む無音設計
- 問いかけ表示切替
- VisionKit複数ページスキャン
- OCR・文字認識なし
- スキャン画像を実PDFとして端末内保存
- PDFKitによる横向き1ページ閲覧
- ログイン、広告、外部通信、共有、クラウド同期なし
