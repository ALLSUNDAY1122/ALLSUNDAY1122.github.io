# 小学生漢字 学習アプリ 仕様書 v0.1

作成: 2026-11-27 / 状態: データ準備完了、仕様ドラフト

## 1. コンセプト

- 小学校で習う漢字1,026字（文部科学省 学年別漢字配当表、平成29年告示・令和2年度全面施行）を、学年別に「読み」と「書き」の両方で学ぶ専用アプリ。
- 対象: 小学1〜6年生とその保護者。
- シリーズ位置づけ: 「ITパスポート 学びスプリント」「FP2級｜学びスプリント」と同じ学びスプリント系。学習記録・苦手復習の仕組みを流用する。
- アプリ名（案）: 「小学生漢字｜学びスプリント」

## 2. データ（準備完了）

ファイル: `data/kanji-1026.json`（1,050,123バイト、1,026件）
生成スクリプト: `data/build_dataset.py`（原データは `data/raw/` に保存）

| 項目 | 出典 | ライセンス |
|---|---|---|
| 学年の配当（1〜6年） | KANJIDIC2 の grade 項目（文科省配当表に準拠） | CC BY-SA 4.0（EDRDG） |
| 音読み・訓読み | KANJIDIC2 | CC BY-SA 4.0（EDRDG） |
| 画数 | KANJIDIC2 | CC BY-SA 4.0（EDRDG） |
| 筆順・字形パス（109×109座標） | KanjiVG r20260714 | CC BY-SA 3.0（Ulrich Apel 他） |

検証済み（2026-11-27）:
- 学年別字数が公式配当と一致: 1年80 / 2年160 / 3年200 / 4年202 / 5年193 / 6年191、合計1,026字
- 1年生の80字が公開されている配当表リストと完全一致
- 2020年改訂で4年生に入った20字（茨・媛・潟・岐・熊・埼・崎・滋・栃・奈・梨・阪・阜・縄など）がすべて4年に含まれる
- 1,026字すべてに筆順パスあり。画数はKANJIDIC2とKanjiVGで不一致ゼロ

各レコードの項目: `kanji` / `grade` / `strokeCount` / `on`（音読み、カタカナ） / `kun`（訓読み、ひらがな。「.」は送り仮名の区切り、「-」は接頭・接尾の印） / `strokes`（画ごとのSVGパス文字列、筆順どおり）

ライセンス対応: アプリ内にクレジット表示（KANJIDIC2 © EDRDG、KanjiVG © Ulrich Apel and contributors、各CC BY-SA）を行う。派生データセット自体もCC BY-SAで扱う。

### 既知の制限
- 読みはKANJIDIC2の全読みを収録しているため、その学年で習う音訓の割り振り（文科省「音訓の段階別割り振り表」）より多い読みが含まれる字がある（例: 「上」のシャン）。v1では全読みを表示し、割り振り表での絞り込みは今後の課題とする。
- 熟語・例文は未収録。読みクイズの選択肢は同じ学年の漢字の読みから生成する。熟語の追加は候補（JMdictから常用熟語を抽出）としてv1.1以降で検討。

## 3. 機能

### 3.1 ホーム
- 学年カード（1〜6年）: 各学年の字数、学習済み字数、正答率、苦手字数（ITパスポート版の分野カードと同じ形式）
- 今日の学習（苦手優先で10字）
- 苦手復習の入口
- 学習状況（総回答数・正答率・苦手数）

### 3.2 読み
- 漢字カード: 大きな漢字、音読み・訓読み（送り仮名は色分け表示）、画数、筆順アニメーションへの導線
- クイズ（4択）:
  - 漢字を見て正しい読みを選ぶ
  - 読みを見て正しい漢字を選ぶ
- 回答は学習記録に残り、間違えた字は苦手に登録（3回連続正解で解除、既存アプリと同じルール）

### 3.3 書き
- 筆順アニメーション: KanjiVGパスを1画ずつ再生（自動再生／1画ずつ進める）
- なぞり書き練習: 薄く表示したお手本の上を指（またはApple Pencil）でなぞる
  - 判定: 画の順番を固定し、各画についてユーザーのストロークの始点・終点がお手本の始点・終点の許容範囲内にあるか照合する。外れたらその画だけ書き直し
  - 書き終わりに「書けた」として記録
- 書きテスト: お手本なし（マス目のみ）で書き、画数と筆順を判定する

### 3.4 テスト
- 学年別まとめテスト: 読みクイズ＋書きテストの混合、結果画面で分野別ではなく読み／書き別の正答率を表示

### 3.5 設定
- Premium（買い切り／月額）、購入の復元
- 学習記録のリセット
- クレジット（データ出典とライセンス）

## 5. 技術

- iOS / SwiftUI（既存アプリと同じ構成、XcodeGen + Codemagic + TestFlight）
- 書き取り入力は DragGesture でストロークを取得し、Path で描画。筆順パスはSVGパス文字列をSwiftUI Pathへ変換して表示・アニメーションする
- 学習記録は既存の StudyRecordStore と同じ方式（UserDefaultsにJSON保存）
- データは `kanji-1026.json` をそのまま同梱（約1.0MB）
