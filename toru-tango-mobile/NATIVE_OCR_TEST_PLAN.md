# Apple Vision OCR 実機テスト計画

更新日: 2026-07-26

## 目的

Apple VisionローカルモジュールがEAS開発ビルドでコンパイルされ、iPhone上で「撮影→OCR→作問→単語帳学習」まで完了することを確認する。

## 前提

- ブランチ: `qa/toru-tango-mobile-20260726`
- Bundle ID: `com.allsunday1122.torutango`
- Expo SDK: 57
- EAS profile: `development`
- `expo-dev-client`: 導入済み
- Apple Developer Program: 加入済み

## ビルド

```bash
cd toru-tango-mobile
npm install --no-audit --no-fund
npx eas-cli login
npx eas-cli build --platform ios --profile development
```

またはCIで`EXPO_TOKEN`を使用する。Secretをコード、Issue、PRコメントへ貼らない。

## ケース1: 横向きの日本語表

対象: ユーザーが提示した保険商品の比較表。

1. 横向き写真を選ぶ
2. 向きは「自動」を選ぶ
3. 「写真から文字を読む」を押す
4. 採用角度が90度または270度になることを確認
5. 認識結果に次の主要語が含まれることを確認
   - 継続入院所得保障保険
   - 14日以上継続入院
   - 給付金月額
   - 契約年齢
   - 法人契約
6. 誤認箇所を編集できることを確認
7. 教材本文へ送る
8. 端末内簡易作問で、支払事由、支払限度、給付金額、契約年齢のカードを生成
9. 保存して表裏反転と両面読み上げを確認

## ケース2: 通常の横書き文章

1. 歴史文章を正立状態で撮影
2. 自動向きで0度が選ばれることを確認
3. 年代、場所、名称を認識できることを確認
4. 同じ事実の一問一答と穴埋めが重複しないことを確認

## ケース3: 手動回転

1. 自動向きで誤った場合を想定
2. 「左へ90°」を選んでOCR
3. 「右へ90°」を選んでOCR
4. 選択した向きが結果表示に反映されることを確認

## ケース4: 権限・失敗

- カメラ権限拒否でクラッシュしない
- 写真権限拒否でクラッシュしない
- 文字のない写真で明確なエラーを表示
- Expo Goでは開発ビルドが必要な案内を表示

## 合格条件

- Swiftネイティブモジュールがコンパイルされる
- iPhoneでOCRがクラッシュせず完了する
- 横向き表の主要項目を認識する
- OCR結果を編集できる
- OCRからカード保存まで中断なく完了する
- 表裏反転と両面読み上げが動作する
