> **置換済み**：2026-07-29のユーザー指示により、当面の実装はGemini API無料枠へ変更した。2026-07-29時点の現行モデルは`gemini-3.5-flash-lite`。本書の20教材と品質基準は再利用するが、モデル名、API、料金、トークン項目は`AI_GEMINI_BENCHMARK.md`を正本とする。

更新日: 2026-07-26

## 目的

GPT-5 nanoを初期標準モデルとして使用できるか判定する。費用の安さだけでは採用せず、単語帳として保存可能な表裏カードを安定して生成できることを確認する。

## 固定設定

- Model: `gpt-5-nano`
- Reasoning effort: `medium`
- Endpoint: OpenAI Responses API
- Output: strict JSON Schema
- 最大作成枚数: 10
- AI失敗時の別モデル自動切替: なし
- AI失敗時の端末内簡易作問自動切替: なし

## 判定基準

各教材について次を記録する。

| 項目 | 記録方法 |
|---|---|
| 生成枚数 | Workerの `quality.acceptedCount` |
| 生出力数 | Workerの `quality.rawCount` |
| 重複除外 | Workerの `quality.duplicateCount` |
| 不適切除外 | Workerの `quality.rejectedCount` |
| 事実誤り | 人が本文と照合して件数記録 |
| 意味重複 | 同じ事実の言い換えを件数記録 |
| 編集不要枚数 | そのまま保存できる枚数 |
| 入力トークン | Workerの `usage.inputTokens` |
| 出力トークン | Workerの `usage.outputTokens` |
| 応答時間 | Workerの `elapsedMs` |

総合採用条件:

- 重大な事実誤り 0件
- 意味重複率 5%以下
- 編集不要率 90%以上
- JSON Schema違反 0件
- 20教材中18教材以上で有効カードを生成

## テスト1：人類史

### 教材

```text
人類史のはじまり

最古の人類、ルーシーの骨（複製）
人類は、数百万年前にアフリカ大陸で誕生した、とされている。

約540万年前アフリカ大陸で、現在のところ最古の猿人とよばれるアウストラロピテクスが登場した。これが最初の人類とされている。東アフリカのタンザニアで、猿人の一種である、ジンジャントロプスの化石が発見された。

エチオピア北東部ハダール村付近では、318万年前のアウストラロピテクス・アファレンシスの化石骨が1974年11月24日に発見され、「ルーシー」と名付けられた。

200万年前から100万年前、アフリカ大陸の北側から生活の場を広げ、ユーラシアを西方へ進む者と東方へ進む者に分かれて広がったと考えられている。
```

### 必須確認

- 「人類史の」のような不完全な答えを作らない
- 同じ事実を一問一答と穴埋めの両方で作らない
- `Zinjanthropus`のような英語表記だけを答えにしない
- ルーシーの年代、発見日、発見場所を混同しない
- 問題数を満たすために低品質カードを追加しない
