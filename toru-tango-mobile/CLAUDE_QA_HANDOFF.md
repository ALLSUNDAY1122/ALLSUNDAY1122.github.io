# Claude QA引き継ぎ書: 撮る単語帳 iOS

更新日: 2026-07-26

## 役割

Claudeは、ChatGPTが実装したリリース候補について、主要操作、UI、文字、余白、Safe Area、エラー表示、空状態を確認する。

問題は次の優先度で分類する。

- P0: 起動不能、クラッシュ、データ損失、復元不能、主要情報の漏えい
- P1: カード作成、学習、保存など主要機能が正常に完了しない
- P2: 見た目、分かりやすさ、操作感、追加改善

P0・P1の中核ロジック修正はChatGPTへ戻す。UI修正はClaudeが反映してよい。TestFlight・署名・申請作業は行わない。

## 起動手順

```bash
cd toru-tango-mobile
npm install
npm run check
npx expo start
```

iPhoneでExpo Goまたは開発ビルドを使用して確認する。SDK 57がExpo Goで利用できない場合はEASのpreview buildを使用する。

## 重点確認

### 1. 初回起動

- 起動時の白画面、無限読み込み、例外
- 最初に「作る」が表示されるか
- 4タブの移動
- iPhoneのノッチ、Dynamic Island、ホームインジケータとの重なり

### 2. 作る

- 教材本文、形式、難易度、問題数の操作性
- AI失敗時のフォールバック表示
- 生成結果の編集と重複除外
- 直接入力と一括入力
- キーボード表示時にボタンへ到達できるか
- カメラ、写真権限を拒否した場合の表示

### 3. 単語帳

- 長い問題・答えの折り返し
- 0件、1件、大量カード時の表示
- 編集中のキャンセルと保存
- 削除、全削除の確認文

### 4. 学習

- 問題、答え、進捗、ボタンの視認性
- 読み上げ中の連続タップ
- 「もう一度」が末尾へ戻ること
- 対象カード0件と完了状態

### 5. 記録

- 小さい画面で統計4項目が崩れないか
- 日別履歴の読みやすさ
- バックアップ保存と復元
- 不正ファイル、キャンセル、共有不可時の表示

## 初期版の確定事項

- iPhone専用
- ライトモード固定
- ログインなし
- 課金なし
- 広告なし
- クラウド同期なし
- AI API未設定でも端末内作問で利用可能
- 写真の撮影・選択は実装済み
- 写真OCRは初回TestFlightの必須機能から除外候補。アプリ名と期待値の不一致がP1相当かを評価する
