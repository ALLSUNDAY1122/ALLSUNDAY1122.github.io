# 撮る単語帳 UX再設計仕様 v1.0

更新日: 2026-08-19
対象: `toru-tango-mobile`
実装branch: `feature/on-device-ai-card-generation`

## 目的

写真/OCR/AI作問で作ったカードを、作成後も長期的に整理・編集・学習しやすい単語帳へ改善する。
既存のOCR・端末内AI・バックアップ互換を壊さず、カード管理と読み上げ学習のUXを全面整理する。

## 1. フォルダ一覧

- 「単語帳」トップをフォルダ中心へ変更する。
- `Card.deckName` をフォルダとして扱う。
- フォルダを2列グリッドで表示する。
- 各フォルダに以下を表示する。
  - フォルダ名
  - カード枚数
  - 学習進捗
  - 未学習/弱点の概要
- フォルダ名検索を提供する。
- 更新日順で並べる。
- フォルダをタップすると、そのフォルダ内カード一覧へ遷移する。
- 新規カード作成導線を常時表示する。

## 2. フォルダ内カード一覧

- 表/裏を同一行で確認できるカード一覧とする。
- 検索対象: 表、裏、メモ。
- フィルター:
  - すべて
  - 未学習
  - 苦手
  - 表示中
  - 非表示
- 並び順:
  - 更新順
  - 新しい順
  - 弱点順
  - 問題順
- 各カードで以下を即操作できる。
  - 表示/非表示
  - 編集
  - 削除
  - 表/裏の読み上げ
- 編集時は表、裏、メモを同一カード内で変更できる。
- 表示/非表示は永続保存し、学習対象の既定値は表示中カードのみとする。

## 3. 学習設定

- 学習の向き
  - 表→裏
  - 裏→表
- 出題順
  - 通常順
  - ランダム
- 出題範囲
  - 表示中のカード
  - すべてのカード
- 学習モード
  - すべて
  - 弱点
  - 定期確認
  - 確認不要
  - 未学習

## 4. 読み上げ仕様

- 音声読み上げON/OFFを提供する。
- 「全文読み上げ」ON時は、現在カードの表→裏を連続して全文読み上げる。
- 全文読み上げ完了後、既定で3秒待って次カードへ自動移動する。
- 自動移動待機時間は `オフ / 1秒 / 2秒 / 3秒 / 5秒` から選択可能とする。
- 既定値は3秒。
- 手動操作を行った場合は待機中の自動送りをキャンセルする。
- 画面離脱時・カード変更時に音声とタイマーを必ず停止する。

## 5. データ互換

- 既存 `Card` に `isHidden?: boolean` を追加する。
- 既存保存データでは `isHidden` が無い場合 `false` とみなす。
- Backup version 1を維持し、既存JSONバックアップを読み込めること。
- OCR/AI生成・CSV追加では `isHidden=false` を既定とする。

## 6. UI方針

- メインアクセントをティール系へ統一する。
- 44pt以上の主要タップ領域を維持する。
- 状態は色だけに依存せず、文言でも示す。
- 表/裏、表示/非表示、未学習/弱点は一覧上で即判別できること。
- 重要操作は深いメニューに隠さず、主要画面から1タップで到達させる。
- 破壊操作は確認ダイアログを維持する。

## 7. 辛口レビュー改善

- 現行の「フィルター→カード→複数ボタン」が縦に長く、一覧性が低い問題を解消する。
- フォルダ選択とカード検索を同一階層に混在させない。
- 表と裏を別ブロックにせず、カード単位で一目比較できる配置にする。
- 学習設定と学習本体の責務を分け、開始前の設定を理解しやすくする。
- 自動読み上げは「何を読み、いつ次へ進むか」を文言で明示する。
- 非表示カードが学習に混入しないよう、既定の対象範囲を明確にする。

## 8. 完了条件

1. フォルダ一覧が表示され、フォルダ選択でカード一覧へ移動できる。
2. フォルダ内で表/裏を同時確認し、編集・削除・表示切替できる。
3. 表示中/非表示フィルターが正しく動作する。
4. 学習対象が表示中カードに限定できる。
5. 全文読み上げ完了後3秒で次カードへ自動移動する。
6. 画面離脱・手動操作時に音声/タイマーが残らない。
7. 既存カード/履歴/バックアップが壊れない。
8. TypeScript、ESLint、Expo Doctor、CIを通過する。
