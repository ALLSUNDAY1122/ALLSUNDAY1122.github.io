# Gemini作問品質ベンチマーク

更新日: 2026-07-29

## 目的

Gemini API無料枠の`gemini-3.5-flash-lite`が、撮る単語帳の初期AI作問モデルとして使用できるか判定する。無料であることだけでは採用せず、教材本文を根拠に保存可能な表裏カードを安定して生成できることを確認する。

## 固定条件

- Provider: Google Gemini Developer API
- Model: `gemini-3.5-flash-lite`
- Endpoint: `generateContent`
- 出力: JSON Schemaによる構造化出力
- 温度: `0.2`
- 最大出力トークン: `3000`
- AI失敗時の別モデル・端末内作問への自動切替: なし
- 既存の`AI_NANO_BENCHMARK.md`にある固定20教材と品質判定を再利用

## 基本実通信

Claudeへ渡す前に最低3教材、可能なら次の5教材で確認する。

1. 通常の日本語説明文
2. 年代・場所・名称を含む歴史文
3. 金額・年齢・期間を含む表形式OCR文
4. OCR空白・罫線ノイズを含む文
5. 確認可能な事実が少ない短文

記録項目:

- model
- requested / raw / accepted / duplicate / rejected
- input / output / total tokens
- elapsedMs
- 生成カード
- 事実誤り、意味重複、不完全な答え

## 採用条件

- 教材本文にない事実を追加しない
- 同一事実の意味重複を保存候補へ残さない
- 答えが問題文に含まれる一問一答を除外できる
- 情報が少ない教材で低品質カードを水増ししない
- 3～5教材の基本実通信でP0・P1がない
- 固定20教材の評価結果をClaude QAで記録する

## 無料枠の注意

- 無料枠にはレート制限があり、上限は変更される可能性がある。
- Googleの料金表では、無料枠の入力・出力が製品改善に使われる旨が示されている。
- 公開前に料金、レート制限、利用規約、データ取扱いを再確認する。
- 無料枠を超えたときに別モデルへ自動切替しない。利用者へエラーを表示する。

## 判定

2026-07-29に通常の日本語説明文を単発送信し、HTTP 200、model `gemini-3.5-flash-lite`、requested 3 / raw 3 / accepted 3を確認した。応答時間は約17.6秒で、教材本文に沿った植物・光合成の3問が生成された。

同じWorkerへ5教材を直後に連続送信した試験は、通常文・歴史文・表形式OCR・OCRノイズ・短文の全件が45秒でタイムアウトした。単発成功後のバースト試験であるため、作問品質ではなく無料枠のレート制限または応答遅延の可能性が高い。間隔を空けて1件ずつ再実行し、3～5教材の品質判定を完了する。

基本実通信と固定20教材の評価が未完了のため、現時点では暫定採用とする。
