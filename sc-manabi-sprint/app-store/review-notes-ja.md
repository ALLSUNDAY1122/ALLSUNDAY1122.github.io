# App Review Notes案

本アプリは「情報処理安全確保支援士試験」の科目A-2学習用アプリです。

## 審査時に確認できる主要導線
1. ホーム → 「今日の8問を始める」
2. 問題回答 → 正誤表示 → 解説 → 「ここだけ覚える」
3. 模試 → 各試験回 → 前半13問／後半12問
4. 記録 → 正答率、分野別、5週間ヒートマップ、苦手一覧
5. 設定 → 4/8/16問、試験日、文字サイズ、JSON入出力

## コンテンツ構成
- IPA公表済み過去問：75問
- 公開シラバス・一次資料に基づく独自問題：250問
- 合計325問

IPA公表過去問には出典を表示し、改変がある場合はその旨を表示します。解説は独自制作です。

2026年度以降の非公開本試験問題は、受験者の記憶、SNS投稿、漏洩情報等から復元していません。

## データ・アカウント
- ログイン不要
- ユーザー登録なし
- 広告なし（初版）
- 第三者解析SDKなし（初版）
- 学習履歴は端末内保存
- 独自サーバーへの個人データ送信なし

## ネットワーク
主要学習機能はアプリ内同梱コンテンツで動作します。問題の一次根拠を確認する外部リンクのみ、ユーザー操作で外部サイトを開きます。

## 権利関係
IPA公表過去問の利用条件を確認し、年度・期・試験区分・時間区分・問番号等の出典表示および改変表示を行います。本アプリはIPAの公式アプリではありません。

## 審査用アカウント
不要です。
