子ども医療費
確認済み0歳から18歳到達年度末までの子どもの保険診療自己負担額の一部を助成する。

年齢目安：生後0か月から18歳まで／手続き：こども医療証の交付申請が必要

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み満1歳から小学3年生までの市内在住児を市立診療センター内の病児保育室で預かる。

年齢目安：生後12か月から9歳まで／利用料：1日2,000円。生活保護世帯は免除。食事提供時は500円

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3～5歳児と住民税非課税世帯の0～2歳児の保育料を無償化し、0～2歳児の多子軽減を継続する。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み令和8年度の市立小中学校の児童生徒に係る学校給食費を徴収しない。

年齢目安：生後72か月から15歳まで／支援内容：令和8年4月1日施行の規則により、当分の間、保護者から学校給食費を徴収しない

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み生後12か月未満までの母子等を対象に、宿泊・通所・居宅訪問型の産後ケアを提供する。

年齢目安：生後0か月から1歳まで／利用形態：宿泊（ショートステイ）型、通所（デイサービス）型、居宅訪問（アウトリーチ）型／利用料：課税世帯の通常料金は宿泊5,190円、通所2,600円、居宅訪問1,000円。非課税・生活保護世帯は軽減

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み生後6か月から満3歳未満の未就園児が、就労要件なしで月10時間まで保育施設を利用できる。

年齢目安：生後6か月から3歳まで／利用料：原則1時間300円。施設により実費やキャンセル料あり

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み市内の対象空き家を購入する子育て世帯・若年者世帯に購入費の2分の1、最大200万円を補助する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み電話で事前申込みし、処理券を貼付して指定日に出す有料の粗大ごみ収集を実施する。

申込方法：高石環境サービスセンターへ電話申込み。月曜から土曜の9時から13時に受付

自治体公式情報（確認日 2026-07-23）
