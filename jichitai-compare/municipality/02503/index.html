風間浦村の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み風間浦村に住所を有する18歳到達後最初の3月31日までの子どもの保険診療自己負担分を給付する。

年齢目安：生後0か月から18歳まで

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
公式情報で詳細未確認第3期子ども・子育て支援事業計画で、病児・病後児保育は村内未実施とされ、令和7～11年度の確保量も0人日としている。

制度がないとは限りません。現行条件は自治体へご確認ください。

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み風間浦村民が風間浦保育所を利用する場合、保育料を無償としている。

年齢目安：生後0か月から5歳まで／保育料：保育料無償

自治体公式情報（確認日 2026-07-23）

学校給食費支援
公式情報で詳細未確認村は学校給食費無償化に取り組んでいることを公式に公表しているが、掲載資料が令和7年度分であり、令和8年度の対象校・対象者・適用期間を確定できない。 現行公式情報で利用条件を確定できないため、情報未確認として整理する。

制度がないとは限りません。現行条件は自治体へご確認ください。

自治体公式情報（確認日 2026-07-23）

産後ケア
公式情報で詳細未確認第3期計画で産後ケア事業を実施し、令和7～11年度に各年度6人回を確保する方針を確認できるが、対象月齢、利用形態、回数、自己負担を確定できない。 現行公式情報で利用条件を確定できないため、情報未確認として整理する。

制度がないとは限りません。現行条件は自治体へご確認ください。

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み令和8年度から、生後6か月から2歳までの未就園児を月10時間まで保育所等で受け入れるこども誰でも通園制度を実施する。

年齢目安：生後6か月から3歳まで

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み村外から転入して住宅を取得・賃借する人や、転入者へ空き家を提供する人へ定住促進奨励金を交付する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み粗大ごみは毎月第4木曜日に粗大ごみ券を貼って排出でき、家庭ごみをクリーンセンターしもきたへ有料で直接搬入できる。

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み津波浸水域・津波基準水位、土砂災害警戒区域、洪水浸水想定区域等を掲載する防災情報と地区別ハザードマップを公開している。
