子ども医療費
確認済み出生から18歳年度末まで県内医療機関の保険診療自己負担を原則無料化

年齢目安：生後0か月から18歳まで／自己負担：県内医療機関でマイナンバーカード等と若年者医療費受給資格者証を提示すると保険診療は原則無料

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み生後6か月から小学校6年生までを対象に2施設で病児・病後児保育を実施

年齢目安：生後6か月から12歳まで／利用料：市内利用者は1日1,500円。生活保護・ひとり親家庭医療費受給・市町村民税非課税世帯は1,000円。希望者は昼食代400円

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3歳以上児、非課税世帯の3歳未満児、第3子以降の保育料を無償化

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み2026年度は食材価格高騰による学校給食費の不足分を市が負担

年齢目安：生後72か月から15歳まで／支援内容：食材価格の高騰によって生じる給食費の不足分を市が負担

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み出産後1年以内を中心に訪問・宿泊・日帰り型の産後ケアと家事育児支援を実施

年齢目安：生後0か月から0歳まで／利用形態：産前産後ヘルパー派遣、訪問型産後ケア、産後ショートステイ、産後デイサービス

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み市内保育園で家庭保育が一時的に困難な乳幼児を預かる一時保育を実施

年齢目安：生後0か月から5歳まで／利用料：1日1人あたり3歳未満児2,000円、3歳以上児1,500円

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み移住定住者の新築・中古住宅取得や空き家改修に補助金を交付

主な条件：原則5年以上定住、税滞納なし、親族間購入は対象外。申請期限は住宅取得日から1年以内

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み申込み制の家庭系粗大ごみ戸別収集を有料で実施

申込方法：環境対策課、美作クリーンセンター、各総合支所の窓口または電話で申込み

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報

情報の見方

「確認済み」は自治体公式情報から主要条件を確認できた制度です。「公式情報で詳細未確認」は制度がないことを意味せず、現行年度の条件を公開情報だけでは確定できない状態です。
