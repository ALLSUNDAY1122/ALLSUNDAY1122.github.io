子ども医療費
確認済み0歳から18歳年度末までの保険診療自己負担を1日800円・月上限1,600円に軽減

年齢目安：生後0か月から18歳まで／自己負担：保険医療機関等ごとに1日800円、月上限1,600円／手続き：福祉医療費受給資格認定申請が必要

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み病児保育Hinamiccoで就学前児を受け入れ、利用料は1日2,000円

年齢目安：生後3か月から5歳まで／利用料：利用料2,000円、給食費500円。Hinamiccoは原則弁当持参

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3～5歳児と非課税世帯0～2歳児を無償化し、0～2歳児の第2子同時在園・第3子以降も無償

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み経済的に就学困難な小中学生世帯へ就学援助で学校給食費や学用品費等を支援

年齢目安：生後72か月から15歳まで／支援内容：学校給食費、学用品費等の経費の一部を援助

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後1年未満の母子へ日帰り・宿泊型産後ケアを提供

年齢目安：生後0か月から1歳まで／利用形態：デイケア、ショートステイ／利用料：デイケア無料。ショートステイは1泊1,500円、2泊目以降500円。生活保護・非課税世帯は無料

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み未就園の生後6か月から3歳未満を月10時間、1時間300円で受け入れ

年齢目安：生後6か月から2歳まで／利用料：1時間300円。給食・おやつ等の実費が別途必要な場合あり

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み子育て世帯の中古住宅リフォーム費を2分の1、上限40万円補助

支援内容：対象リフォーム工事費の2分の1／主な条件：町税滞納がなく、対象住宅に長期間居住する意思があること。交付決定前着工は対象外

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み地域ごとに年2回無料収集し、処理施設への直接搬入は100kgごと600円

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報

掲載情報：洪水浸水想定区域、土砂災害警戒区域、地震、避難所・避難経路等

情報の見方

「確認済み」は自治体公式情報から主要条件を確認できた制度です。「公式情報で詳細未確認」は制度がないことを意味せず、現行年度の条件を公開情報だけでは確定できない状態です。
