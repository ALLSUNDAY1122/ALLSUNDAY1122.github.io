宮城県・自治体制度情報

岩沼市

北日本調査班Bが岩沼市公式情報で対象9制度を調査し、すべて確認済み。18歳年度末までの医療費助成、病児保育、第2子以降保育料無償化、令和8年度学校給食費支援、産後ケア等を反映。

岩沼市の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み0歳から18歳到達年度末まで、保険診療による自己負担額を助成する。

年齢目安：生後0か月から18歳まで／手続き：あらかじめ受給資格登録が必要

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み市内在住の小学6年生までを対象に、病気の回復期前でも1日2,000円で病児保育を行う。

年齢目安：生後0か月から12歳まで／利用料：1日2,000円（給食費を含む）

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3～5歳児と住民税非課税世帯の0～2歳児を無償化し、市独自に第2子以降の保育料も所得・きょうだい年齢を問わず無償化する。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み令和8年度は小学校給食費を実質無償化し、中学校は1食当たり80円の物価高騰分を補助する。

年齢目安：生後72か月から15歳まで

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後12か月未満の母子へ宿泊・通所・訪問型の産後ケアを合計7回まで提供する。

年齢目安：生後0か月から1歳まで／利用形態：宿泊型、通所型6時間、訪問型2時間

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み生後6か月から3歳未満の未就園児が、就労要件を問わず月10時間まで1時間300円で利用できる。

年齢目安：生後6か月から3歳まで／利用料：1時間300円

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み39歳以下・所得合計500万円未満等の新婚世帯に、住宅取得・賃料・リフォーム・引越費用を最大60万円補助する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み粗大ごみは予約制の戸別収集を利用でき、手数料は50kgごと1,000円、1回5点まで。

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み洪水・津波・土砂災害・ため池・地震等の各種ハザードマップと避難所情報を公開する。

自治体公式情報（確認日 2026-07-23）

情報の見方

「確認済み」は自治体公式情報から主要条件を確認できた制度です。「公式情報で詳細未確認」は制度がないことを意味せず、現行年度の条件を公開情報だけでは確定できない状態です。
