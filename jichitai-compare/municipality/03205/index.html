花巻市の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み出生から18歳到達後最初の3月31日まで、所得制限なしで保険診療の自己負担額を助成する。

年齢目安：生後0か月から18歳まで／自己負担：乳幼児と住民税非課税世帯は無償。課税世帯の小学生以上は同一医療機関で月額上限が入院2,500円、通院750円／所得制限：なし／手続き：医療費受給者証を国保医療課または各総合支所市民サービス課で申請

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み生後6か月から小学6年生までの病気回復期の児童を、花巻市病後児保育室で預かる。

年齢目安：生後6か月から12歳まで／施設数：1施設／利用料：日額2,000円、5時間未満は1,000円

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み0～2歳児の第2子以降の保育料を無償化し、第1子も国基準から約40％引き下げる。3歳以上の副食費も第2子以降を無償化する。

年齢目安：生後0か月から5歳まで／保育料：0～2歳児の第1子は国基準から約40％引下げ、第2子以降は無償／多子軽減：0～2歳児保育料と3歳以上副食費は第2子以降無償／所得条件：第2子以降の市独自無償化について所得条件の記載なし

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み令和8年度は小学校給食費を完全無償化し、中学校は食材料費の価格高騰分を市が負担して保護者負担を据え置く。

年齢目安：生後72か月から15歳まで／支援内容：小学校給食費を完全無償化。中学校は価格高騰分を市が負担／対象校：花巻市立小中学校

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後1年未満の母子を対象に日帰り型・訪問型・宿泊型の産後ケアを実施し、令和8年度のサービス利用料は無料。

年齢目安：生後0か月から1歳まで／利用形態：日帰り型、訪問型、宿泊型／利用料：令和8年度はサービス利用料無料。食事代・消耗品等は自己負担

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み保育施設等に在籍していない生後6か月から満3歳未満の子どもが、就労要件を問わず月10時間まで利用できる。

年齢目安：生後6か月から3歳まで／利用形態：市内5施設で時間単位利用／利用料：1時間300円。施設により異なる場合があり、非課税世帯等は減額の場合あり

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み18歳未満の子と同居する子育て世帯が、同居・近居または生活サービス拠点内で住宅を取得する場合に奨励金を交付する。

支援内容：基本30万円。大迫・東和地域は50万円。都市機能誘導区域内は20万円加算、第2子以降は1人10万円加算／主な条件：交付請求日に18歳未満の子と同居し、親族との同居・近居または生活サービス拠点内で住宅取得、市税滞納なし

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み不燃性粗大ごみは花巻市清掃センターへ直接搬入でき、可燃性粗大ごみは岩手中部クリーンセンターへ搬入する。

料金体系：不燃性粗大ごみは10キログラムごと260円。不燃ごみは10キログラムごと70円で家庭ごみ50キログラムまで無料／申込方法：花巻市清掃センターで受付・車両計量後に搬入し、再計量して精算

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み令和8年4月更新の地域別ハザードマップ、指定緊急避難場所・指定避難所、デジタルマップを公開している。

掲載情報：洪水浸水想定区域、土砂災害警戒区域、指定緊急避難場所、指定避難所、ため池情報／確認方法：花巻・大迫・石鳥谷・東和地域別PDFとはなまきデジタルマップで確認
