村田町

北日本調査班Bが村田町公式情報で対象9制度を調査。8制度を確認済みとし、病児・病後児保育は町公式情報で専用制度の現行利用条件を確認できないためunavailableとして記録。

村田町の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み0歳から18歳到達年度末まで、保険診療の自己負担分を助成する。

年齢目安：生後0か月から18歳まで

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
公式情報で詳細未確認町公式の子育て案内で病児・病後児保育の専用制度、実施施設、対象年齢、料金、利用方法を確認できない。

制度がないとは限りません。現行条件は自治体へご確認ください。

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3～5歳児クラスの保育料は無償。0～2歳児は町民税課税状況等に応じた額で、非課税世帯等は0円となる。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み村田町に住民登録があり町立小中学校に在籍する児童生徒の学校給食費は徴収しない。

年齢目安：生後72か月から15歳まで

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み町内在住の産後12か月未満の母子に、宿泊・通所・訪問型の産後ケアを提供する。

年齢目安：生後0か月から1歳まで／利用形態：宿泊型、通所型6時間、訪問型2時間

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み町内在住で保育所等に在籍していない満1歳以上の未就園児を、半日500円で一時的に預かる。

年齢目安：生後12か月から5歳まで／利用料：午前500円、午後500円。児童1人あたり

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み転入世帯または中学生以下の子育て世帯による町内住宅取得に、新築30万円・中古15万円等を補助する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み粗大ごみは収集所に出せず、処理施設へ直接搬入するか町許可業者へ依頼する。

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み防災読本、防災マップ、洪水マップ、避難場所等を町公式サイトで公開する。

情報の見方

「確認済み」は自治体公式情報から主要条件を確認できた制度です。「公式情報で詳細未確認」は制度がないことを意味せず、現行年度の条件を公開情報だけでは確定できない状態です。
