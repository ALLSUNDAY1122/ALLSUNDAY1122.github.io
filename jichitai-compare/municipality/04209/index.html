多賀城市

北日本調査班Bが多賀城市公式情報で対象9制度を調査し、すべて確認済み。18歳年度末までの医療費助成、病後児保育、小学校給食費無償化、産後ケア、住宅窓断熱改修補助等を反映。

多賀城市の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み0歳から18歳到達後最初の3月31日まで、保険診療の自己負担分を助成する。

年齢目安：生後0か月から18歳まで

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み1歳児から小学3年生までを対象に、下馬みどり保育園で病後児保育を実施する。

年齢目安：生後12か月から9歳まで／利用料：1日2,000円、4時間未満1,000円。生活保護世帯は免除

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3～5歳児と住民税非課税世帯の0～2歳児は、幼児教育・保育無償化の対象となる。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み令和8年度は市立小学校の給食費を全額公費負担とし、中学校は1食136円を補助する。

年齢目安：生後72か月から15歳まで

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後1年未満の母子へ、通所・訪問・宿泊型の産後ケアを各類型7回まで提供する。

年齢目安：生後0か月から1歳まで／利用形態：通所型2時間・3時間・6時間、訪問型2時間・3時間、宿泊型

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み生後6か月から3歳未満の未就園児が、就労要件を問わず月10時間まで利用できる。

年齢目安：生後6か月から3歳まで／利用料：標準1時間300円。生活保護世帯等は負担軽減あり

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み国の対象事業を利用した市内住宅の窓断熱改修に対し、自己負担相当額の2分の1、上限10万円を補助する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み粗大ごみは規格内であれば収集日に1世帯1個まで排出でき、大量ごみは許可業者依頼または有料直接搬入を利用する。

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み洪水・土砂災害・津波・地震等の危険区域と避難所をまとめた防災ハザードマップを公開する。

情報の見方

「確認済み」は自治体公式情報から主要条件を確認できた制度です。「公式情報で詳細未確認」は制度がないことを意味せず、現行年度の条件を公開情報だけでは確定できない状態です。
