いわき市の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み出生から18歳到達後最初の3月31日まで、保険診療の自己負担額と入院時食事療養費を助成する。

年齢目安：生後0か月から18歳まで／手続き：社会保険等加入者は事前の受給資格登録と受給者証交付が必要

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み生後6か月から就学前までの病気の回復期等にある乳幼児を、市内4施設で無料で預かる。

年齢目安：生後6か月から6歳まで／利用料：無料。昼食・おやつ等は持参

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3～5歳児と住民税非課税世帯の0～2歳児は無償化対象で、その他の0～2歳児は年齢・市民税額等に応じた保育料となる。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み令和8年度の市事業一覧に、小学生向けおよび中学生・第3子以降向けの学校給食費無償化事業を位置付ける。

年齢目安：生後72か月から15歳まで

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後12か月以内の母子を対象に、宿泊型と日帰り型の産後ケアを実施する。

年齢目安：生後0か月から1歳まで／利用形態：宿泊ケア、日帰りケア。訪問型は未実施

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み保育所等に通っていない生後6か月から満3歳未満の子どもが、月10時間まで1時間300円で利用できる。

年齢目安：生後6か月から3歳まで／利用料：1時間300円。施設によりその他費用あり

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み市外から移住する子育て世帯の引越費用を、県外移住は最大10万円、県内移住は最大5万円支援する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み家庭の大型ごみはLINEまたは電話で事前予約し、納付券を貼って戸別収集を受ける。

申込方法：市公式LINEまたは居住地区の大型ごみ受付センターへの電話で事前予約

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み河川洪水、津波浸水、土砂災害、避難所・避難場所等を地区別にまとめた令和8年改訂防災マップを公開する。

掲載情報：河川洪水、津波浸水、土砂災害、避難所、避難場所、津波避難ビル等

情報の見方

「確認済み」は自治体公式情報から主要条件を確認できた制度です。「公式情報で詳細未確認」は制度がないことを意味せず、現行年度の条件を公開情報だけでは確定できない状態です。
