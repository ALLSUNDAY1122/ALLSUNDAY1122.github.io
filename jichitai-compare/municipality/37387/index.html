子ども医療費
確認済み出生から18歳年度末まで保険診療の自己負担分を助成

年齢目安：生後0か月から18歳まで／手続き：子ども医療費受給資格者証の交付申請が必要

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み生後6か月から小学校6年生まで町内2施設の病児・病後児保育を利用可能

年齢目安：生後6か月から12歳まで／利用料：町内在住児は1日2,000円、5時間以内1,000円。食事代等は別途

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3歳児以上を無償化し、0～2歳児は町民税額と多子区分により算定・軽減

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み2026年度は町立小中学校等の学校給食費を実質無償化

年齢目安：生後72か月から15歳まで／支援内容：学校給食費補助金交付要綱に基づき、2026年度の給食費を実質無償化

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後1年未満の母子へ宿泊・通所・訪問型産後ケアを提供

年齢目安：生後0か月から0歳まで／利用形態：短期入所型、通所型、訪問型

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み未就園の生後6か月から満3歳未満へ月10時間のこども誰でも通園制度を実施

年齢目安：生後6か月から2歳まで／利用料：1時間300円。おやつ代45円、副食費190円等は別途

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み既存住宅の断熱改修を2分の1・上限20万円補助

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み家庭の粗大ごみを高松市西部クリーンセンターへ有料で直接搬入可能

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
