潟上市の9制度

子ども医療費
確認済み0歳から18歳到達後最初の3月31日までの子どもの保険診療自己負担額を全額助成する。

年齢目安：生後0か月から18歳まで／所得制限：父母の所得判定あり

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
公式情報で詳細未確認市公式情報では病児保育事業が無償化対象事業として示されるが、現行の実施施設・対象年齢・利用時間・料金を確認できない。

制度がないとは限りません。現行条件は自治体へご確認ください。

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3歳児から5歳児は全員、0歳児から2歳児は住民税非課税世帯の基本保育料が0円となる。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
公式情報で詳細未確認小中学校の全児童生徒を対象とする給食費無償化・一律軽減は公式情報で確認できない。教育・保育施設の3～5歳児は給食費が無償で、就学困難世帯には給食費を含む就学援助がある。

制度がないとは限りません。現行条件は自治体へご確認ください。

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み潟上市に住民票がある産後1年までの母子に、デイサービス型・宿泊型の産後ケアを提供する。

年齢目安：生後0か月から1歳まで／利用形態：デイサービス型、宿泊型

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み保育施設等に通っていない市内の未就学児を、就労・傷病・育児疲れ等の際に一時預かりする。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み子育て世帯や移住・定住世帯の住宅リフォーム・中古住宅購入等に補助し、県外移住者には暮らし応援助成金も支給する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み40センチメートル以上のごみを粗大ごみとして区分し、便利帳・品目別手数料表を公開し、クリーンセンターへの自己搬入も受け付ける。

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み津波・土砂災害・ため池・洪水のリスクと避難所等を確認できるWEBハザードマップを公開する。
