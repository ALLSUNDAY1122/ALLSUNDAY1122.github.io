秋田市の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み出生から18歳到達年度末までの子どもの保険診療自己負担額の全部または一部を助成する。

年齢目安：生後0か月から18歳まで／自己負担：0歳は自己負担なし。1歳以上は世帯の市町村民税課税状況等により一部自己負担が生じる場合がある／所得制限：所得による資格除外なし

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み生後9週から小学6年生までの病気治療中の児童を病児保育室で預かり、回復期児童向けの病後児保育も実施する。

年齢目安：生後2か月から12歳まで／利用料：病児保育は1回2,000円。所得等に応じ減免制度あり

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み3歳から5歳の教育・保育利用料と、住民税非課税世帯の0歳から2歳の利用料を無償化する。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み令和8年度は小学校給食費を無償化し、中学校給食費は公費補助により1食340円に軽減する。

年齢目安：生後72か月から15歳まで

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後1年以内の母子を対象に、宿泊型と通所型の産後ケアを提供する。

年齢目安：生後0か月から1歳まで／利用形態：短期入所型（宿泊）と通所型（デイサービス）

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み教育・保育施設に在籍していない乳幼児を、保護者の就労、疾病、育児負担軽減等に応じて一時的に預かる。

年齢目安：生後2か月から5歳まで／利用料：施設ごとに設定。保育の必要性認定を受けた3歳から5歳および非課税世帯の0歳から2歳は上限額の範囲で無償化対象

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み県外から秋田市へ移住する子育て世帯の住宅取得・賃貸初期費用・引越費用を、30万円に子1人10万円を加算した上限額まで補助する。

主な条件：転入前の移住登録、県内就業または市内起業等の要件があり、転勤・公務員世帯等は対象外

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み粗大ごみは電話またはインターネットで事前申し込みし、品目に応じた手数料を納付して指定日に排出する。

申込方法：電話またはインターネットで事前申し込み

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み洪水、津波、土砂災害、高潮、内水等のハザードマップと指定避難所情報を公開する。
