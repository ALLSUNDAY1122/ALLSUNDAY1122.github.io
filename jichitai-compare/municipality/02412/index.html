青森県・自治体制度情報

おいらせ町

北日本調査班Aが対象9制度をおいらせ町公式情報で調査し、全9制度を確認済み。高校卒業相当年齢までの医療費助成、病後児保育、令和8年度からの保育料・副食費無償化、学校給食費無料化、産後ケア、こども誰でも通園制度等を反映。

おいらせ町の9制度

制度の正式な対象可否は、世帯状況や申請時期によって変わります。申請や転居の判断前に、必ず自治体の公式サイトまたは担当窓口で最新条件をご確認ください。

子ども医療費
確認済み0歳から18歳到達年度末までの子どもの保険診療自己負担を原則無料とする。

年齢目安：生後0か月から18歳まで／手続き：出生・転入後に受給資格認定申請。償還払いは診療翌月から6か月以内

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み保育所等を利用中で病気の回復期にあり、集団保育が困難な子どもを専用スペースで一時的に保育する。

年齢目安：生後0か月から6歳まで

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み令和8年度から、町が決定する保育料と国基準額までの副食費を無償化する。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
確認済み町内小中学校の学校給食費を全額無料とし、給食のない学校等へ通う町民には補助制度を設ける。

年齢目安：生後72か月から15歳まで

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後1年未満の母子を対象に、委託施設で宿泊・通所・訪問型の産後ケアを実施する。

年齢目安：生後0か月から1歳まで／利用形態：宿泊型1泊2日、通所型1日または半日、訪問型3時間以内

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み未就園の生後6か月から満3歳未満の子どもが、就労要件を問わず月10時間まで園を利用できる。

年齢目安：生後6か月から3歳まで／利用料：標準利用料は1時間300円。実額は施設により異なる

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み甲洋小・下田小学区へ住宅取得等で転居する子育て世代に、新築上限100万円、中古上限60万円等を助成する。

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み指定袋に入らない粗大ごみは処理券を購入して予約収集を利用するか、十和田地域広域事務組合へ有料で自己搬入する。

申込方法：本庁舎町民課、分庁舎町民課分室、北部出張所で予約

自治体公式情報（確認日 2026-07-23）

防災・ハザード情報
確認済み津波、洪水、土砂災害、ため池、火山等の危険区域と避難所を掲載した防災安全マップを公開する。

情報の見方

「確認済み」は自治体公式情報から主要条件を確認できた制度です。「公式情報で詳細未確認」は制度がないことを意味せず、現行年度の条件を公開情報だけでは確定できない状態です。
