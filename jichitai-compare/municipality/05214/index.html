子ども医療費
確認済み出生から18歳年度末までの子どもの保険診療自己負担額を所得制限なく助成する。

年齢目安：生後0か月から18歳まで／所得制限：なし

自治体公式情報（確認日 2026-07-23）

病児・病後児保育
確認済み生後6か月から小学6年生までの病児と、小学3年生までの病後児を市民無料で預かる。

年齢目安：生後6か月から12歳まで／利用料：にかほ市民は無料

自治体公式情報（確認日 2026-07-23）

保育料・第2子軽減
確認済み0歳から5歳まで全世帯の保育料と3歳以上児の副食費を所得制限なく全額補助する。

年齢目安：生後0か月から5歳まで

自治体公式情報（確認日 2026-07-23）

学校給食費支援
公式情報で詳細未確認全児童生徒を対象とする学校給食費の無償化・一律軽減は公式情報で確認できず、就学援助認定世帯は給食費支援を受けられる。

制度がないとは限りません。現行条件は自治体へご確認ください。

自治体公式情報（確認日 2026-07-23）

産後ケア
確認済み産後4か月未満の母子に宿泊型・デイサービス型、産後1年未満の母子に訪問型の産後ケアを提供する。

年齢目安：生後0か月から1歳まで／利用形態：宿泊型、訪問型、デイサービス型

自治体公式情報（確認日 2026-07-23）

一時保育・誰でも通園
確認済み未就園児の一時預かり一般型を複数の保育施設で実施し、にかほ市民の利用料を全額助成する。

年齢目安：生後0か月から5歳まで／利用形態：一般型、満3歳以上の幼稚園型

自治体公式情報（確認日 2026-07-23）

子育て世帯向け住宅支援
確認済み50万円以上の住宅リフォーム等に対し、一般型最大10万円、子育て・空き家型は最大20～30万円を補助する。

主な条件：市内業者施工、交付決定後着工、年度内完了等

自治体公式情報（確認日 2026-07-23）

粗大ごみ料金
確認済み粗大ごみは環境プラザまたは地域の一般廃棄物処理施設へ直接搬入し、有料で処理する。

自治体公式情報（確認日 2026-07-23）
