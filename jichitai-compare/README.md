# 自治体くらべ MVP

日本地図から自治体を選び、子育て・住宅・公共サービスを比較する静的サイトの試作版です。

## 現在の機能

- クリックできる日本地図（外部SVGの読み込み失敗時は都道府県一覧に切替）
- 自治体名検索
- 最大3自治体の比較
- 子どもの年齢による簡易対象判定
- 自治体公式サイトと制度出典へのリンク
- 江戸川区・市川市・浦安市の確認済みサンプルデータ
- JSONデータの簡易検証スクリプト

## 技術構成

- HTML / CSS / Vanilla JavaScript
- 静的JSON
- GitHub Pagesで動作
- サーバー、データベース、APIキー不要

この構成は、ChatGPTまたはCodexがファイル更新だけで自治体・制度を追加できることを優先しています。

## データ追加

`data/municipalities.json` の `municipalities` 配列へ自治体を追加します。追加後は次を実行します。

```bash
npm run validate
```

## 次の開発順序

1. 東京23区・千葉県北西部へ拡張
2. 保育料、給食費、産後ケア、住宅支援を追加
3. 市区町村境界地図を都道府県単位で追加
4. 世帯条件判定のルールをJSON化
5. 比較結果の共有URLを実装
6. 独自ドメイン・広告表示方針を決定

## データ方針

- 原則として自治体公式ページを出典とする
- 各制度に確認日を付ける
- 不明な項目は推測せず「調査中」と表示する
- 判定結果は参考情報であり、正式な対象可否は自治体へ確認する

## 地図ライセンス

日本地図は Geolonia `japanese-prefectures` を使用します（GFDL）。
