# #12 不動産鑑定士｜学びスプリント TestFlight Notes（ja-JP）

更新日: 2026-08-13

## Beta App Description
不動産鑑定士試験・短答式の公式過去問を短い反復で学ぶiPhoneアプリです。令和8・7・6年の行政法規・鑑定理論を各40問、合計240問収録しています。8問スプリント、年度別80問、年度×科目40問、苦手復習、学習記録、JSONバックアップを確認できます。

## What to Test
1. ホームの「8問はじめる」から5択問題を解けること。
2. 「わからない」で記録し、次の問題へ進めること。
3. 模試タブで令和8・7・6年の年度別80問を開始できること。
4. 各年度の「行政法規」「鑑定理論」から40問演習を開始できること。
5. 誤答・わからない問題が苦手へ登録されること。
6. 苦手問題は3連続正解で解除されること。
7. 学習を途中でホームへ戻しても再開できること。
8. 記録タブで正答率・既習数・苦手数・5週間履歴が表示されること。
9. 設定で1日4/8/16問、文字サイズ、試験日を変更できること。
10. JSONバックアップを書き出し、読み込めること。
11. 令和8年鑑定理論39・40の条件表を文章化した表示が読みやすいこと。
12. 解説から国土交通省の一次資料リンクを開けること。
13. 機内モードでも収録問題を学習できること。
14. Dynamic Island、ホームインジケータ周辺に黒帯・欠け・操作不能がないこと。
15. クラッシュしないこと。
