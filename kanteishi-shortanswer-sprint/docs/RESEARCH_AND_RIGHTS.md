# 開発連番#12 調査・権利方針

確認日: 2026-08-13

## 市場性

国土交通省公表の不動産鑑定士試験・短答式受験者数は、令和6年1,675名、令和7年2,144名、令和8年2,407名。令和6年から令和8年で約43.7%増加している。大規模資格ではないが、直近の受験者増加は明確で、短答式に絞った反復学習アプリを投入する市場根拠はある。

現行App Storeには、鑑定理論の一問一答、行政法規を含む総合型、過去問・基準・進捗管理を備える競合が存在する。#12は単なる一問一答ではなく、学びスプリント共通Golden Masterに沿う8問スプリント、年度×科目導線、模試、苦手3連続正解解除、わからない記録、中断復帰、履歴、JSONバックアップ、完全オフラインを組み合わせて差別化する。

## 出題範囲と固定問題枠

令和8年短答式は次の2科目。

- 不動産に関する行政法規: 択一式、120分
- 不動産の鑑定評価に関する理論: 択一式、120分

令和8年試験案内では、出題は原則として令和7年9月1日現在施行の法令等に基づく。鑑定理論は不動産鑑定評価基準および同運用上の留意事項を対象とする。

国土交通省公開PDFを確認し、令和8・7・6年は各年度とも行政法規40問＋鑑定理論40問＝80問。3回分の固定枠は240問とする。この240枠を別問題として管理し、水増しで埋めない。

## 国土交通省コンテンツの利用条件

国土交通省ウェブサイト利用規約では、別の権利表示等がないコンテンツについて公共データ利用規約（PDL1.0）に準拠した利用が認められている。PDL1.0は、対象コンテンツについて複製、公衆送信、翻訳・変形等の翻案、商用利用を含む利用を認める一方、出典記載、編集・加工した場合の表示、第三者権利や個別法令等の遵守を求める。

国土交通省の「本利用ルールが適用されないコンテンツ」一覧を確認した範囲では、不動産鑑定士試験問題は例外として列挙されていない。令和8・7・6年の短答式問題PDF・正解表について、抽出対象本文に第三者出典・転載・Copyright等の明示を検出しなかった。

したがって、今回の240問は国土交通省公表資料としてPDL1.0に基づき利用し、各問題へ出典・編集表示・権利根拠を保持する。

## 製品240問の最終権利監査

- 対象: 令和8・7・6年 × 行政法規40＋鑑定理論40 = 240問
- canonical: `questions/exam-2026.json` / `exam-2025.json` / `exam-2024.json`
- origin_type: `licensed_official`
- license: PDL1.0
- 第三者権利要確認キュー: **0件**
- exact duplicate group: **0件**
- 人工水増し: **0件**

初期自動判定では「情報の提供」「財務諸表」「公表」等を図版・第三者権利語と誤認したため、単語部分一致を廃止し、明示的な出典・転載・Copyright表記だけを権利シグナルとするよう修正した。

## 表レイアウト問題

令和8年鑑定理論の問39・問40は表形式の前提条件を含むため、権利問題とは分離してレイアウト監査を実施した。

### 問39
土地A・Bの併合による限定価格。表を数値関係を保持した箇条書きへ再構成。

- 併合前A+B: 157,500,000 + 245,000,000 = 402,500,000円
- 併合後C: 440,000,000円
- 増分価値: 37,500,000円
- 単価比A: 525,000 / (525,000 + 490,000) ≒ 0.517
- 配分額: 約19,388,000円
- 総額比A: 157,500,000 / 402,500,000 ≒ 0.391
- 配分額: 約14,663,000円
- 公式正解: (3)

### 問40
原価法による積算価格。前提条件表を文章化。

- 親族施工値引き前建設費: 20,000,000円
- 工事物価10%補正後再調達原価: 22,000,000円
- 経過10年 + 経済的残存30年 = 経済的総耐用年数40年
- 定額法減価: 22,000,000 × 10/40 = 5,500,000円
- 建物: 16,500,000円
- 土地50,000,000円を加算: 66,500,000円
- 公式正解: (4)

両問とも `layoutReviewStatus = pass_text_reconstruction` としてcanonicalへ記録した。

## 問題生成・監査ルール

1. 令和8・7・6年×2科目×40問の240スロットを先に固定する。
2. 各スロットは `edition / subject / officialQuestionNo / appQuestionId` の対応を保持する。
3. 原文利用時は出典、確認日、編集・加工有無、第三者権利確認結果を保存する。
4. `explanation / ここだけ覚える / evidence / evidenceCheckedDate` が欠ける問題を製品データへ昇格させない。
5. 重複ID、完全一致、高類似、正答不整合、根拠欠損、法令基準日の不整合を自動監査する。
6. 公式試験での実再出題は史実として年度別canonicalに保持し、通常学習では完全一致をcanonical化する。
7. 法改正時は影響範囲を再監査し、現行学習用の注記と当時試験時点の正答を混同しない。
8. 最終machine auditは作業用抽出物ではなくGitHub canonical 3ファイルを結合した240問へ再実行する。
