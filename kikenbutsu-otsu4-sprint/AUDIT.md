# 危険物取扱者 乙種4類｜学びスプリント Safari価値検証版 監査記録

更新: 2026-08-08

## 1. 収録範囲

- 独自問題: 36問
- 法令: 15問
- 物理・化学: 10問
- 性質・消火: 11問
- 本番35問: 法令15 / 物理・化学10 / 性質・消火10を抽出
- 通常学習: 選択肢タップで即時採点
- 本番モード: 正誤を伏せて終了時に一括採点

## 2. 一次監査｜正答・論理整合

全36問について次を確認した。

- 選択肢は各5個
- 正答インデックスは0〜4の範囲
- 正答と「この問題で覚える一文」が一致
- 詳細解説が正答と矛盾しない
- 数値問題の単位をLで統一
- 指定数量の倍数計算は各数量÷指定数量の合計で計算
- 本番35問の3科目配分が15/10/10になる

判定: 36/36 PASS

対象ID: L01〜L15 / P01〜P10 / S01〜S11

## 3. 二次監査｜独自性・権利依拠

- 公式過去問題本文を転載していない
- 公式過去問題の設問順・選択肢配列を原稿として使用していない
- 市販問題集・他社アプリの解説文を原稿として使用していない
- 法令・危険物分類・基礎理論の論点から問題文、誤答選択肢、短解説を独自作成した
- 製品版360問へ拡張する際は、各問題に一次資料URL、確認日、法令基準日、contentVersionを保持する

判定: 36/36 独自作問方針 PASS

注意: 本記録は開発上の権利リスク管理であり、法律意見ではない。公開前に公式利用条件と法令改定を再確認する。

## 4. 辛口レビュー 第1周｜迷い

想定低評価:
- どこから始めればよいか分からない
- 科目が多く見える
- プレミアム対象が分かりにくい

確認・改善:
- ホーム最上位を「今日の12問」に固定
- 中断時だけ「続きから」を最上段に追加
- 科目別は法令 / 物理・化学 / 性質・消火の3枚だけ
- PREMIUM対象は苦手復習 / 数字・指定数量 / 本番35問に限定表示
- 課金対象を押したときだけ説明画面へ遷移

判定: PASS

## 5. 辛口レビュー 第2周｜テンポ

想定低評価:
- 回答までタップが多い
- 解説が長い
- 次へ進むのが遅い

確認・改善:
- 通常問題は選択肢タップ＝即時採点
- 独立した「回答する」ボタンなし
- 詳細解説は折りたたみ
- 「この問題で覚える一文」を先に表示
- 本番だけは実試験再現のため選択→次問とし、正誤は終了時まで非表示
- 再描画時にタイマー監視が重複する可能性を検出し、runtime.jsで単一タイマー化

判定: PASS

## 6. 辛口レビュー 第3周｜継続

想定低評価:
- 前回の続きが分からない
- 間違えた問題だけやりたい
- 何周したか分からない
- 文字が小さい

確認・改善:
- 問題ID列、現在位置、回答、開始時刻をlocalStorageへ保存
- 「続きから」で1タップ復帰
- 誤答・わからないを苦手へ登録
- 苦手は3連続正解で自動解除
- 今日の12問・科目別の完答回数を保存
- 学習記録に累計解答、正答率、科目別正答率、直近履歴を表示
- 標準 / 大 / 特大の文字サイズを実装
- prefers-reduced-motionへ対応

判定: PASS
