# FP2 初回リリース品質ゲート（2026-11-23）

期限: 2026-11-24 08:00 JST。状態: 計画確定・未監査・未提出。

## スコープ
学科6分野各20問、計120問を上限目標。四肢択一・正答一意・各肢理由・根拠URL・適用法令基準日を必須とする。60問への縮小を許容するが、未監査問題の出荷は禁止。実技・課金・AI機能・600問固定は対象外。既存問題は自動承認せず再監査する。

## 原典
日本FP協会 2級試験範囲 https://www.jafp.or.jp/exam/subjects_02/ ; 2026年度試験日程・法令基準日 https://www.jafp.or.jp/exam/schedule/index.shtml ; 試験要綱 https://www.jafp.or.jp/exam/outline/ 。2026年11月受検の法令基準日: 2026-04-01。

## 必須ゲート
Q0: 権利・出典・逐語転写疑義・出典の再利用条件。転写が滞る場合は公式シラバスと一次資料に基づく独自問題へ切替。
Q1: 問題ID重複ゼロ、4肢、正答一意、全肢根拠、数値検算、法令基準日一致、再現可能な監査台帳。
Q2: 製品UIにリリースJSONを実際に読み込み、収録件数と表示件数一致、学習・復習・進捗保存・再起動・オフライン動作確認。
Q3: iPhone実機検証、ビルド成功、配信・プライバシー表示、App Store Connectメタデータ・スクリーンショット・署名確認。

## 停止条件
いずれかの必須ゲート未達なら提出可能と宣言しない。既存のHTML内サンプル問題を本番問題として数えない。App Review提出は別途品質確認後。

## PR計画
本ブランチでリリース範囲と監査ゲートを固定。続いて問題バンク生成元、製品UI接続、テストをコミット。ゲートが揃ってからmain向けPRをReady化する。
