## 結論

**現行360問は製品版の本試験対策問題銀行として不合格。**
正答・解説の事実監査とは別に、難易度と選択肢品質を全問目視した結果、約7割が本試験レベルの識別負荷に達していない。

## 横断的な欠陥

1. **極端語で誤答が見抜ける**
   - `必ず / すべて / 一切 / 絶対 / 不要 / 起こらない / 無制限` を誤答へ多用。
   - 正答だけが `場合がある / 必要に応じて / 確認する / 相談する` と丁寧な条件付き文になる。

2. **正答だけ長く自然**
   - 正答が説明文、誤答が短い断定文という文体差が多く、知識より文章パターン認識で解ける。

3. **無関係な誤答肢**
   - 肝臓の問題に「音を感じる」「尿を蓄える」、唾液の問題に「胆汁・尿・酸素・血液凝固」など、同一論点で競合していない。
   - 第3回でも成分重複問題に「箱の色・メーカー・価格・錠剤サイズ」、副作用報告情報に「好きな色・商品棚・広告閲覧数」が混在。

4. **一問一答化しすぎ**
   - `成分名 → 用途`、`器官 → 主要機能`、`制度名 → 定義` の単純対応が多く、本試験で必要な複数知識の同時判定になっていない。

5. **受診勧奨が常識問題化**
   - 高熱・呼吸困難・大量出血等に対し「受診」が正答、誤答が「倍量」「無視」「長期継続」という問題が多い。
   - 専門知識を問うなら、受診基準、禁忌成分、症候群鑑別、使用期間、対象年齢等を近接させる必要がある。

## 良い問題の特徴

A判定には以下の傾向がある。
- 薬物用量反応の順序
- 年齢区分
- 薬害の原因・疾患の識別
- 重大副作用の症候群識別
- 甘草→偽アルドステロン症
- ヒマシ油×駆虫薬
- 特定販売の定義
- 販売業許可の更新年数、店舗面積、照度、勤務時間比率
- 2026年5月施行後の指定濫用防止医薬品の年齢・氏名・購入状況確認
- 安全性速報/緊急安全性情報/副作用報告/救済制度の具体要件

これらは「知らなければ選べない」ため、改稿後の基準モデルとする。

## 360問改稿ルール

1. D 117問は全面再作問。
2. C 134問は正答テーマを活かしてもよいが、誤答肢を全面再設計。
3. B 62問は近接概念を入れて難化。
4. A 47問も法令・正答・表現を再確認したうえで維持。
5. 5択は同一論点・同一専門用語レベルに揃える。
6. 正答だけ長い/丁寧/条件付きになることを禁止。
7. 極端語を誤答の目印として使わない。
8. 各120問の40〜60問を a〜d の複数記述正誤組合せ型へ移行する。
9. 第2章は器官の無関係選択肢を廃止し、構造・機能・薬物動態・副作用の近接比較へ変更。
10. 第3章は同効成分、作用機序、副作用、禁忌、相互作用、年齢、妊娠等を組み合わせる。
11. 第4章は数字・区分・販売従事者・情報提供義務・陳列・確認事項の近接制度比較にする。
12. 第5章は発出主体・色・対象・報告要件・救済給付要件を交差させる。
13. 改稿後に再度120問単位で同じ監査を行い、C+Dを各回20%以下まで下げる。
