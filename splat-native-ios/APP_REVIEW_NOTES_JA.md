# Scan Lab｜App Review / TestFlight Notes

更新日: 2026-08-17

## このビルドの目的

本ビルドはScan Labの3Dスキャン、ローカル保存、およびD2の共有・公開機能を検証する開発版です。iPhoneホーム画面上の表示名は `Scan Lab` です。

主な経路は、カメラ撮影→端末内3D生成→ローカル保存→ユーザーが明示的に選択した場合のみアカウント／公開共有／Map・Discover連携、です。

## アカウント

D2共有機能ではSupabase Authを利用します。アカウントを作成・利用した場合、メールアドレス、ユーザーID、プロフィール表示名をアプリ機能提供のためアカウントに関連付けて扱います。広告目的・第三者トラッキングには利用しません。

## 権限

- Camera: 3Dスキャン生成用の撮影に使用します。スキャンを開始した時に要求します。
- Location When In Use: Mapへ公開する地点をユーザーが明示的に設定する操作でのみ使用します。バックグラウンド取得や自動公開は行いません。
- Photos: 要求しません。
- Microphone: 要求しません。
- Notifications: 要求しません。
- Tracking: 要求しません。ATTダイアログも表示しません。

Info.plistの説明文:
- Camera: `周囲を撮影して端末内で3Dスキャンを生成するため、カメラを使用します。`
- Location: `Mapへ公開する地点をユーザーが明示的に設定した場合だけ、現在地を取得します。位置情報は自動送信しません。`

## データ取扱い / Privacy Manifest

撮影画像、ARKitカメラ姿勢、ARKit特徴点、生成途中の3Dデータは、通常の撮影・再構成経路ではアプリコンテナ内で処理します。オフライン撮影・再構成・ローカル保存のコア経路からSupabase/URLSessionへ送信しないことを回帰gateで検査します。

D2共有機能を利用した場合に収集し得るデータは次のとおりです。いずれもユーザーに関連付けられ、App Functionality目的、Tracking=falseとしてPrivacy Manifestに宣言します。

- Name: 公開プロフィール表示名
- Email Address: 認証
- User ID: アカウント、所有権、公開データの関連付け
- Precise Location: ユーザーがMap公開地点を明示設定した場合のみ
- Other User Content: ユーザーが公開操作した3Dスキャン／公開メタデータ

`NSPrivacyTracking = false`、tracking domainsなしです。広告SDK・解析SDKはD2に追加しません。

## 公開・位置情報の同意

公開はユーザー操作を必須とし、公開前にコンテンツ確認を要求します。位置付き公開はさらに公開地点の確認を要求します。位置情報を取得しただけで自動的に公開・送信する設計にはしません。

## アカウント削除

アカウント機能を提供するビルドでは、アプリ内からアカウント削除導線を提供し、所有データと認証情報の削除処理をD2 lifecycleとして扱います。

## 暗号化

アプリ独自の非免除暗号化機能は実装していません。`ITSAppUsesNonExemptEncryption = NO` を設定しています。

## Review確認手順

1. `新しくスキャン` からカメラ権限を許可し、3Dスキャンを作成します。
2. 通常の撮影・生成・ローカル保存では位置情報権限を要求しないことを確認します。
3. 共有／公開機能へ進み、公開が明示操作であることを確認します。
4. Map公開地点を設定する操作でのみ位置情報権限が要求されることを確認します。
5. 位置付き公開では公開地点の確認が必要で、自動公開されないことを確認します。
6. Tracking権限、Microphone、Photos、Notificationsが要求されないことを確認します。

## 審査時の申告整合性

App Store ConnectのApp Privacy回答は、このリポジトリの `SplatNative/PrivacyInfo.xcprivacy` と本ノートを正本として一致させます。機能追加で収集データ、用途、リンク性、tracking、権限が変わる場合は、コードだけを先行させずManifest・permission文言・Review説明・回帰gateを同一変更で更新します。
