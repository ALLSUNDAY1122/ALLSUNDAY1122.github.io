## TestFlight向け説明

Scaniverse個人向けiOS体験との機能・実用品質同等化を目的に、静止物・シーンの周囲をiPhoneで撮影し、撮影画像・ARKitのカメラ姿勢・特徴点から3D Gaussian Splatを端末内で生成する検証版です。

中心経路は「撮影 → 端末内3D生成 → 3D表示」です。S7では、明示操作によるクラウド保存、公開/限定リンク、ブラウザ3D共有、Map、Discover、アカウント、削除・非公開化、報告機能を追加しています。

## 実装と一致させる申告

- ログイン: あり。メールアドレス/パスワード方式。ローカル撮影・端末内生成には不要
- 広告: なし
- 課金: なし
- 広告トラッキング: なし
- 解析SDK: なし
- クラウド基盤: Supabase（認証、DB、Storage、Edge Functions）
- カメラ: 使用する
- 写真ライブラリ権限: 使用しない
- マイク: 使用しない
- 位置情報: Mapへ公開する際、ユーザーが明示的に現在地を公開地点として設定した場合だけ使用
- 通知: 使用しない
- 収集する可能性のあるデータ: メールアドレス、ユーザーID、表示名、ユーザーがクラウドへ保存/公開した3D・プレビュー・投稿情報、明示的にMapへ公開した位置情報、いいね・報告操作
- 利用目的: App Functionality
- 独自暗号化: なし

撮影画像・ARKit姿勢・特徴点・3D生成処理は端末内で行います。ユーザーが `オンライン共有・公開` を選び、さらに公開操作を確定するまで、3Dファイルや位置情報をScan Labのクラウドへ自動送信しません。

公開範囲は次の3種です。

1. 非公開: 自分のアカウント用クラウド保存
2. 限定リンク: Map/Discoverには出さず、専用URLを知る人だけが閲覧
3. 公開: Map/Discoverおよび共有URLから閲覧可能。位置情報と安全確認が必須

公開・限定リンクの3D本体は非公開Storageに置き、閲覧時のみ短時間の署名URLを発行します。アカウントおよびクラウドデータはアプリ内から削除できます。

## Internal TestFlight 実機テスト手順

### A. ローカル中心経路

1. アプリを起動し、`Scan` タブで `新しくスキャン` を押す。
2. カメラ利用を許可する。
3. 模様のある静止物を中央に置き、対象の周囲を止まらずゆっくり1周する。
4. `撮影方向 x / 12` が増えることを確認する。
5. `3Dを生成` を押し、端末内生成を完了する。
6. 回転、ピンチ拡大縮小、ダブルタップ初期化を確認する。
7. `3Dを書き出す` でiOS共有シートが開くことを確認する。

### B. S7オンライン経路

1. `Account` タブからテスト用アカウントを作成またはログインする。
2. 生成済み3Dで `オンライン共有・公開` を開く。
3. `非公開` でクラウド保存でき、共有URLが発行されないことを確認する。
4. 別の3Dを `リンクを知っている人のみ` で公開し、専用URLをSafariで開いて3Dを操作できることを確認する。
5. 別の3Dを `マップ・Discoverに公開` にし、位置情報の明示設定と3つの安全確認がないと公開できないことを確認する。
6. `Map` と `Discover` から公開3Dを開き、3D操作・いいね・報告導線を確認する。
7. `Account` から公開解除、個別削除、最後にアカウント削除が機能することを確認する。
8. 公開解除/削除後は共有URLから取得できないことを確認する。

## S7確認上の重要点

- ログイン前でもローカル撮影と端末内3D生成ができる。
- 明示操作なしに3Dや位置情報が外部送信されない。
- private / unlisted / public の境界がサーバー側でも強制される。
- ダミー投稿でMap/Discoverを埋めない。
- 公開コンテンツの報告と所有者削除が機能する。
- 本審査提出前にApp Store ConnectのPrivacy回答を本ファイルとPrivacy Manifestに一致させる。
