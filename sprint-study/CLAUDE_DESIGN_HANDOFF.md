## 2. 製品定義 — 変更禁止

製品名: 学びスプリント

位置づけは単なる学習タイマーではなく、**学習ペースメーカー**です。

中心価値:
- 「何分勉強したか」を測るのではない
- 「1ページ・1問を何秒で進めるか」を決める
- または「ここまでを何分で終わらせる」から必要ペースを逆算する
- 開始後は教材を見たまま、原則スマホを触らず自動進行する

差別化3点:
1. `秒数を決める` / `ゴールから逆算` の2モード
2. 終了後に平均 `秒/ページ・問・語・枚・回` を記録
3. 任意の段階加速。セットごとに制限時間を短くできる

この製品定義をデザイン上も伝わるようにしてください。

## 5. 音の仕様 — 変更禁止

実機フィードバックを反映済みです。

- 柔らかい自然な音は集中中に聞き逃すため不採用
- 学習開始: 短い単音
- 学習→切替: 高めの2連電子音
- セット休憩: 下降2音
- 全完了: 3連上昇音
- 音と振動は独立ON/OFF
- BGMは禁止

デザイン変更でこの仕様を戻さないでください。

## 6. デザイン改善の目的

現在版は機能は承認済みですが、見た目はまだWeb試作感があります。
以下を改善してください。

### 最重要

1. **一目で学習ペースメーカーだと分かること**
2. **10秒以内に設定して始められること**
3. **タイマー実行中は視線移動を最小化すること**
4. **iPhoneアプリらしい密度・階層・余白にすること**
5. **シンプルさを維持しながら、無料のWebツール感をなくすこと**

### 見直してよい項目

- 色設計
- タイポグラフィ
- 余白
- カード表現
- ボタン階層
- 入力欄デザイン
- モード切替の見せ方
- 逆算結果の見せ方
- 円形タイマーの質感
- 状態ごとの色
- 履歴の見せ方
- 完了画面
- Bottom navigation
- micro interaction / transition
- アイコン（顔文字・安っぽい絵文字は禁止）

### 避ける方向

- グラデーション多用
- ネオン
- ゲーム風
- AI生成UIにありがちなカードだらけの画面
- ガラス表現の多用
- 装飾のためだけの巨大イラスト
- 説明文過多
- 学習中の情報追加
- タブや画面を増やすこと
- 参考アプリの色・ブランド・トレードドレスの模倣

## 7. 画面ごとの優先順位

### A. 実行画面 — 最優先

ユーザーは教材を見るため、スマホを凝視しません。

必須情報:
- 状態
- 巨大な残り時間
- 現在のページ / 問題番号
- 現在回数 / 全回数
- セット
- 前へ / 一時停止 / 次へ
- 終了

現在の大きな円形タイマー思想は維持して構いません。
ただし、より洗練されたiOSアプリとして完成させてください。

### B. 新規スプリント

`秒数を決める` と `ゴールから逆算` が直感的に理解できること。
逆算は本アプリ最大の差別化なので、通常タイマーの付属機能のように見せないこと。

### C. ホーム

前回設定と保存タイマーから即開始できることを最優先。
トップに説明を増やしすぎないこと。

### D. 履歴 / 完了

時間ではなく **学習速度** が主役。
`平均 47秒/ページ` が視覚的に認識しやすいこと。
複雑なグラフは不要です。

## 9. 作業方法

1. `app-v1.2.0.html` を読んで現状を把握する
2. 機能・JSロジックを変えない前提でデザイン方針を決める
3. **辛口UIレビュー → 改善を3サイクル** 行う
4. 新規ファイルとして `sprint-study/app-v1.3.0-design.html` を作る
5. `app-v1.2.0.html` は上書きしない
6. `index.html` は変更しない
7. ユーザー確認前に通常公開版を差し替えない
