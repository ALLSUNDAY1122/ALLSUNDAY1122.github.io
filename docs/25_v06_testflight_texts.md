# AI引継ぎ帳 v0.6 TestFlight入力文面

作成日：2026年7月24日

## Beta App Description

複数の生成AIを使う長期作業の現在地、担当、タスク、実行結果、決定事項、指示、リスク、成果物を端末内で整理し、次のAIや新しいセッションへ渡す引継ぎ文を作成するアプリです。アカウント登録は不要で、主要機能はオフラインで利用できます。

## What to Test

AI引継ぎ帳は、複数の生成AIで進める長期作業の現在地・担当・タスク・実行ログ・指示・リスク・成果物を整理し、次のセッションへ渡すMarkdown形式の引継ぎ文を生成する端末内保存型アプリです。

重点確認項目

1. 初回説明からデモプロジェクトへ進めること
2. プロジェクト、AI担当、タスク、ログ、指示、リスク、成果物の追加・編集・切替
3. 引継ぎ文の生成、コピー、OS共有
4. JSONバックアップの保存と復元
5. ライト・ダーク・端末連動テーマ
6. アプリ再起動後のデータ保持
7. 機内モードで主要機能が利用できること
8. 日本語の文字化け、画面切れ、クラッシュがないこと

本アプリは生成AIサービスへ接続せず、AIによる回答生成は行いません。アカウント、広告、課金、解析、トラッキング、外部サーバーはありません。バックアップJSONは暗号化されないため、個人情報や秘密情報をテストデータへ入力しないでください。
