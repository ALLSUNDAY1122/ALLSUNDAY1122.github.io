# AI引継ぎ帳 公開後運用チェックリスト

## 公開当日

- [ ] App Storeの商品ページが日本で表示される
- [ ] アプリ名、サブタイトル、説明、スクリーンショットが正しい
- [ ] Privacy Policy URLがHTTPSで表示される
- [ ] Support URLがHTTPSで表示される
- [ ] Supportページからプライバシーポリシーへ移動できる
- [ ] Supportページの問い合わせボタンが機能する
- [ ] App StoreからiPhone 16へ新規インストールできる
- [ ] 初回説明からデモプロジェクトへ進める
- [ ] VersionとBuildが公開対象と一致する
- [ ] オフラインで主要機能が利用できる
- [ ] JSONバックアップの保存と復元が利用できる
- [ ] 引継ぎ文のコピーとOS共有が利用できる

## 公開後24時間

- [ ] App Store Connectでクラッシュや異常な指標がないか確認
- [ ] GitHub IssuesにP0・P1相当の報告がないか確認
- [ ] Privacy URLとSupport URLが継続して表示される
- [ ] 説明やスクリーンショットと実際の機能に不一致がないか確認
- [ ] 問い合わせに個人情報・秘密情報が含まれていた場合は、公開返信で内容を引用しない

## 公開後7日

- [ ] 不具合報告をP0・P1・P2へ分類
- [ ] 同一原因のIssueをまとめる
- [ ] 改善要望を「初回版の修正」「次期版候補」「対応しない」に分類
- [ ] App Storeレビューへ反論・誘導・報酬提供を行わない
- [ ] App Privacy回答と実装の差分が発生していないか確認
- [ ] 外部SDK、広告、解析、ログイン、クラウド同期、AI APIを追加する場合は、実装前にPrivacy PolicyとApp Privacy回答を再設計

## 不具合重大度

### P0：致命的

- 起動不能、頻繁なクラッシュ、フリーズ
- データ消失、別プロジェクトへのデータ混入
- バックアップ復元によるデータ破壊
- 意図しない外部送信
- 認証情報や秘密情報の露出

対応：公開停止や緊急修正版を検討し、原因確認まで新機能作業を止めます。

### P1：重大

- プロジェクト、タスク、ログ、引継ぎ、バックアップなど主要機能が完了できない
- 再起動後に主要データが保持されない
- 主要ボタンが押せない、本文が読めない
- App Store説明にある機能が利用できない

対応：次の修正版を優先し、回避策がある場合はIssueへ安全に記載します。

### P2：軽微

- 誤字、余白、軽微な表示ずれ
- 回避可能で、データや主要操作へ影響しない問題

対応：次期更新候補として管理します。

## 問い合わせ対応ルール

- 個人情報、顧客情報、秘密情報を再掲しない
- パスワード、秘密鍵、アクセストークンを要求しない
- 実データの共有を要求しない
- 再現確認は架空データで依頼する
- 対応可否、回避策、修正対象Versionを明確にする
- 確認できていない原因を断定しない
