# AI引継ぎ帳 0.6.0 リリースノート

初回公開予定版：Version `0.6.0` / Build `6`

## 概要

複数の生成AIを使って進める長期作業を、現在地・担当・タスク・実行ログ・指示・リスク・成果物まで一か所に整理するiPhone向けアプリです。

次のAIや新しいセッションへ渡すMarkdown形式の引継ぎ文を生成できます。

## 主な機能

- 複数プロジェクトの作成、編集、切り替え
- AI担当、役割、稼働状態、利用制限の管理
- タスクの担当、優先度、状態、進捗率の管理
- 実行ログ、決定事項、成果、次のアクションの記録
- プロンプトや運用指示の版管理
- リスク、対応策、成果物保存先の整理
- Markdown形式の引継ぎ文生成
- 引継ぎ文のコピーとiOS共有シート
- JSONバックアップの保存と復元
- ライト、ダーク、端末設定連動テーマ

## プライバシー

- アカウント登録なし
- 開発者サーバーへのデータ送信なし
- 広告なし
- アクセス解析なし
- トラッキングなし
- AI APIへの接続なし
- 登録内容は原則として端末内に保存

OS共有機能を使用した場合は、利用者が選択した共有先へ引継ぎ文が送られます。JSONバックアップは暗号化されないため、個人情報、顧客情報、パスワード、秘密鍵、アクセストークン、未公開情報は入力しないでください。

## 対応環境

- iPhone専用
- Portrait表示
- iOS 13.0以降

## 初回版の制限

- iPadには対応していません
- クラウド同期はありません
- 複数端末の自動同期はありません
- AIによる回答生成は行いません
- JSONバックアップは暗号化されません

## サポート

不具合や改善要望は、GitHubの「AI引継ぎ帳｜不具合報告」または「AI引継ぎ帳｜機能要望」フォームから送信してください。

投稿時には、個人情報、顧客情報、パスワード、秘密鍵、アクセストークン、未公開情報、アプリへ登録した実データを含めないでください。
