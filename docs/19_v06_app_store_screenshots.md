# AI引継ぎ帳 v0.6 App Storeスクリーンショット

作成日：2026年7月24日

## 構成

1. 長期作業の現在地を、ひと目で
2. AIごとの役割とリスクを整理
3. タスクの担当と優先度を明確に
4. 指示の版と実行ログを蓄積
5. 次のAIへ渡す文章を自動生成

## 出力条件

- 1290 × 2796 px
- PNG
- RGB
- 透過なし
- 実際のFlutter UIをウィジェットテストで描画
- サンプルデータは架空の自治体比較サイト制作プロジェクト

## 公開範囲

スクリーンショット生成用コードとCIのみをドラフトPRへ追加する。mainへは未マージのため、公開サイトには影響しない。
