# v5追加メモ（Claude担当・2026-08-18）

## 1. 主要30レッスンを5地域共通の6テーマに再構成（最重要の変更）

これまでは地域ごとに異なる6つの話題（例：イギリスは「電車の遅延」「本の交換会」…、アメリカは「新しい勤務体系」「宅配ピックアップ」…）を用意していたため、地域を切り替えても「別の話」になってしまい、本来やりたかった「同じ文章をアクセント違いで聞き比べる」ができていなかった。

今回、データ構造を以下のように変更した。

- 6つの共通テーマ（Coffee Order Mix-Up／A Hybrid Work Schedule／Weather Changes the Plan／Learning Something New Online／A Sudden Power Outage／Choosing How to Commute）を新規に書き下ろし
- 各テーマの `title`・`topic`・英文（`en`/`short.en`）・日本語訳（`ja`/`short.ja`）・文節データ（`segments`）・設問（`questions`）は5地域すべてで完全に同一
- 地域ごとに変わるのは `id`・`region`・`voices`（話者ロースター）・`audio`（音声ファイルパス）のみ
- 結果として、既存の「地域チップ／地域カード」で地域を切り替える操作が、そのまま「同じ英文を別アクセントで聞く」機能になった。リスニング画面の国チップ列の下に「↑ 地域を切り替えると、同じ英文を別のアクセントで聞けます」という案内文を追加

## 2. 台本の長さの意味を反転

- 従来：オリジナル台本（60〜90語）を「標準」、そこから書き下ろした短縮版（35〜45語）を「短め」としていた
- 変更後：オリジナルの語数感（56〜67語程度）を「短め」の基準とみなし、そこから約2倍の情報量に書き足した新しい台本（115〜136語、平均比率2.05倍）を「標準」として新規執筆
  - 追加した情報量は、状況描写・心情・展開の詳細（例：単なる「注文を間違えられた」ではなく、店の混雑具合や相手の対応、その後どう解決したかまで含む）
  - どちらの長さでも同じ3設問に正しく答えられるよう、事実関係（数字・時刻・結論など）は両方の台本に必ず含めている

## 3. アクセント比較機能（v4で追加）を独立モードとして統合・削除

v4で追加した「🌍 同じ文章を5つのアクセントで」という別建てのモード（ホーム画面のカード、専用のテーマ一覧・比較プレーヤー画面、`data/compare.json`）は、上記1.の再構成によって本編のレッスンで同じことができるようになったため、重複機能として削除した。

- ホーム画面の「アクセントを聞き比べる」カードと関連画面（`#screen-compare-list`、`#screen-compare-player`）を削除
- `window.COMPARE_THEMES` の埋め込みデータ、関連JS（`renderCompareList`/`renderComparePlayer`/`playCompareCurrent`など）を削除
- `data/compare.json`・`data/compare.js`・`audio/compare/` 配下の30本の音声ファイルは、本パッケージには含めていない（本編に統合されたため不要と判断）

## 4. 音声の再生成（312本）

新しい台本内容に合わせて、標準156本＋短め156本＝計312本すべてをAzure Speech（Neural TTS）で再生成した。地域ごとに実行を分割し、Canada→Australia→United Kingdom→United States→India（Indiaはさらに前半/後半に分割）の順に生成。全ファイルの存在とサイズ（1KB超）を確認済み。

## 5. 重要な実装上の注意（今後も有効）

- **index.htmlの1本目の`<script>`タグにはdata/lessons.jsの内容をそのまま埋め込んでいる。** lessons.json/lessons.jsを更新した場合は、必ずindex.html内の埋め込みJSONも上書きし直すこと（今回も再実施済み）
- `scripts/generate_audio_azure.py` に `FORCE_REGEN=1`（既存ファイルを無条件に再生成）、`REGION_FILTER`（地域指定）、`SLOT_FILTER`（テーマ番号指定、例："03,04"）の3つの環境変数を追加した。台本内容を変更したのにファイルパスが変わらない場合、これらを使って確実に再生成できる
- 出力フォルダ配下のファイルは削除（`rm`）ができない制約があるが、既存ファイルへの上書き（`write_bytes`等）は問題なく行える。今後同様の再生成が必要な場合は削除を試みず上書きで対応すること

## テスト

jsdomで新規98項目を検証（全項目パス）。主な確認内容：30レッスンの構造、6テーマ×5地域で題名・英文・日本語訳・設問が完全一致していること（地域は意図的に不一致）、短め/標準の語数比が1.6〜2.5倍の範囲内（平均2.05倍）であること、312本の音声ファイルがすべて実在すること、標準/短めで別の音声パスを参照していること、`contentFor()`が長さ設定に応じて正しく切り替わること、アクセント比較機能関連のDOM要素・グローバル変数が完全に削除されていること、地域一覧画面・全30レッスンナビゲーション・設問の妥当性が引き続き正しく動作すること。
