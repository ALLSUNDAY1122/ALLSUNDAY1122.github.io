# v6追加メモ（Claude担当・2026-08-19）

v5に対して「辛口レビュー→改善」を3回実施し、そのまま実装まで行った。

## 1回目：フリーミアムが新しい売り（アクセント比較）を隠していた問題

v5で「同じ英文を5地域で聞き比べる」構成に変えたにもかかわらず、無料版は Canada（話者2人）のみに閉じていたため、無料ユーザーは一度もこの核心機能を体験できなかった。オンボーディングにもこの機能への言及がなかった。

- 各テーマの1問目「Coffee Order Mix-Up」を、5地域すべてで無料開放（`FREE_SLOT='01'`）。無料ユーザーでも1テーマ分は全アクセントを聞き比べられる
- ロック判定をレッスン単位に変更（`isLessonLocked()`）。地域カード・地域一覧・国チップのいずれも、個別レッスン単位で🔒表示に統一
- 副次的に見つけたバグも修正：「次の音源」ボタン等で使う`goTo()`がロック判定を一切行っておらず、premiumを迂回して有料レッスンに到達できてしまっていた。`goTo()`内でロックチェックし、ロック中はプレミアム誘導モーダルを表示するよう修正
- リスニング画面の国チップは、地域一覧画面を経由せず「同じテーマ番号のレッスンへ直接ジャンプ」するように変更。これにより「チップをタップ→即座にアクセントが切り替わる」という、ホーム画面のヒント文と一致する体験になった（従来は一覧画面を挟む2タップ操作だった）
- オンボーディング1枚目を「同じ話を、5つのアクセントで聞き比べ」という訴求に差し替え
- ロックモーダル・設定画面のプラン説明文も新しい無料範囲に合わせて更新

## 2回目：vocabフィールドが空のまま放置されていた問題

全30レッスンの`vocab`が常に空配列で、UIのどこからも参照されない未使用スキーマだった。標準台本を2倍の分量にした一方で語彙サポートが皆無だった。

- 6テーマ共通のキーフレーズを5個ずつ執筆し、`vocab`に格納（例：Coffee Order Mix-Up → by mistake / point it out / apologize right away / mix-up / turned out even better）
- リスニング画面に「重要表現」パネルを新設し、選択中のレッスンに応じて表示

## 3回目：長さトグルの情報不足とデフォルトの急な変化

「短め／標準」ボタンに語数・所要時間の目安がなく、標準の意味をv5でこっそり2倍に変えたことの説明もアプリ内になかった。

- 各ボタンに「約60語・約30秒」のような目安をレッスンごとに動的表示（`lengthLabelFor()`）
- 新規ユーザーのデフォルトを「短め」に変更（既存ユーザーの保存済み設定は上書きしない）
- 短めを3問クリアした時点で、まだ標準を勧めていなければホーム画面に「標準を試す」ナッジカードを1回だけ表示
- 設定画面の教材情報テキストも、短めスタート＋標準は約2倍という説明に更新

## テスト

jsdomで新規37項目を検証（全項目パス）。主な確認内容：新規ユーザーのデフォルトが「短め」であること、Canadaは常に無条件で解放されていること、非Canada地域の1問目（テーマ01）のみ無料で残り5問はロックされること、`goTo()`がロック中のレッスンへの遷移を拒否しモーダルを開くこと、無料スロットへは地域を問わず遷移できること、devPremium有効化で全レッスンが解放されること、国チップのクリックが地域一覧を経由せず同じテーマ番号へ直接遷移すること（無料スロット・プレミアム時の両方）、アクセント比較の独立機能が引き続き存在しないこと、全30レッスンでvocabが5件ずつ存在し同一テーマ内では5地域で完全一致すること、重要表現パネルが正しく描画されること、長さトグルのラベルに語数が表示されること、3問クリア前後でのナッジ表示・非表示の切り替え、「標準を試す」「今はいいです」それぞれのボタン動作、プレミアム時の全30レッスンナビゲーション。
