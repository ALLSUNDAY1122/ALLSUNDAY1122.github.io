# 保健師国家試験｜330問コンテンツ設計正本

更新: 2026-08-13 JST

## 0. この文書の位置づけ

本書は、独自問題330問を生成・監査する前の論点正本である。

- 3回 × 110問 = 330問
- 1回 = 一般75問 + 状況設定35問
- 出題基準トップレベル10分類を各回11問ずつ扱う
- 各回11問×10分類=110問
- 10分類均等は本アプリの学習設計であり、厚生労働省が公表する科目別出題割合を意味しない
- 2026-03-19制度改善検討部会報告書に従い、令和5年版出題基準を継続し、現行出題数を維持する
- 状況設定問題は原則3連問とし、35問を11組×3問 + 1組×2問で構成する
- 保健師の状況設定では地域診断等の判断力を問うため、人口・健診・相談・地域資源等のデータを使う
- 一般問題はTaxonomy I / I-prime / II、状況設定問題はII / IIIを中心とする
- 改正法令、最新統計、最新制度を扱う問題は公開前に必ず再監査する

## 3. 各回の問題タイプ配分

各回110問のうち75問を一般、35問を状況設定とする。

分類ごとの11問は、一般7〜8問・状況設定3〜4問に分ける。5分類を「一般7・状況4」、残る5分類を「一般8・状況3」として合計を75/35にする。偏りを固定しないため、4問の状況設定を置く分類はRoundごとにローテーションする。

### Round 1

状況4問: A / C / D / F / H
状況3問: B / E / G / I / J

### Round 2

状況4問: B / D / E / G / I
状況3問: A / C / F / H / J

### Round 3

状況4問: A / B / E / H / J
状況3問: C / D / F / G / I

各回とも状況設定問題合計35問になることを機械監査する。

## 4. 状況設定問題の設計ルール

- 原則、同一scenarioIdで3問を連結する
- 各回1組のみ2連問とする
- scenarioTextは共通表示し、問題文はscenarioTextを重複コピーしない
- 1問目: 状況把握・地域診断
- 2問目: 優先課題・追加情報の選択
- 3問目: 介入・評価・連携の判断
- 2連問の場合は「状況把握」と「介入判断」を基本とする
- 3問すべてが単なる知識再生にならないようTaxonomy II/IIIを割り当てる
- 地域診断問題では可能な限りデータ表を独自生成する
- 第三者図表・写真は使わず、必要な視覚素材は自作データ表・自作チャートに限定する

## 6. 監査ゲート

### Structure Gate

- 330問ちょうど
- 3回×110問
- 各回10分類×11問
- 各回一般75問・状況35問
- 各回状況設定11組×3問 + 1組×2問
- ID重複0
- 必須フィールド欠損0

### Originality Gate

- 完全一致0
- 高類似0
- 正解だけ入れ替えた問題0
- 数字だけ変更した問題0
- 選択肢順だけ変更した問題0
- 同一論点の3回分は「基礎／適用／比較・例外」で能力差があること

### Evidence Gate

- source_url欠損0
- reference_date欠損0
- law_baseline_date欠損0
- rights_basis欠損0
- `original_from_primary_source`を原則とする
- 最新統計を問う問題は統計公表年を明示
- 改正予定法令は「現在施行中」と「将来施行」を混同しない

### Medical / Policy Gate

- 正答内容を一次資料で再確認
- 法令問題は施行日を確認
- 統計問題は調査年と公表年を確認
- 制度改定を検知した場合は関連問題を再監査

## 7. 現時点の重要な制度更新

2026年8月時点で、令和8年3月19日の制度改善検討部会報告書は次を示している。

- 令和5年版出題基準は現時点で見直さない
- 現行の出題数を維持する
- 現行の試験時間を維持する
- 保健師の状況設定では地域診断等の判断力を問うためデータ化された情報を活用する方向を維持する
- 状況設定問題は原則3連問とする
- 最新の統計データや改正法令を問う方針を維持する
- 視覚素材の活用を継続する

このため、初期Foundationで固定した令和5年版出題基準・110問構成は失効させず、状況設定の品質要件を強化する。
