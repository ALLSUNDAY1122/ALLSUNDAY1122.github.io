## BASIC-10 不妊・不育 5問

- 女性要因: 排卵、卵管、子宮、年齢等を多面的に評価 — PASS
- 男性要因: 造精、精路、勃起・射精等を含み、カップル双方を評価 — PASS
- 不育症: 抗リン脂質抗体・子宮形態等が関係する場合がある一方、原因不明例もあり心理支援が必要 — PASS
- ART: 成功保証とせず、不確実性、多胎妊娠、OHSS等のリスクと説明・同意を扱う — PASS
- 心理社会支援: 本人・パートナー、仕事、費用、治療継続/休止/終了を含む選択支援 — PASS

現行性: 日本産科婦人科学会「不妊症」（2025-07-28更新）と、こども家庭庁「みんなで知ろう、不妊症不育症のこと」を2026-08-13に再確認。

## BASIC-11 出生前検査 5問

- 概念・目的: 出生前検査で全ての先天性疾患が分かるという誤解を排除 — PASS
- 倫理・意思決定: 検査の限界、結果後の選択肢・支援、本人の価値観を重視 — PASS
- 確定的検査: 羊水検査・絨毛検査を侵襲性のある確定的検査として区別 — PASS
- 非確定的検査: NIPT等をスクリーニングとし、陽性だけで確定しない — PASS
- PGT: ARTで得た胚を対象とする着床前検査で、適応・限界・遺伝カウンセリングを必要とする — PASS

現行性: こども家庭庁「妊娠中の検査に関する情報サイト」とJSOG PGT-A/SR現行ページを2026-08-13に再確認。NIPT陽性を確定診断として扱う問題はない。
